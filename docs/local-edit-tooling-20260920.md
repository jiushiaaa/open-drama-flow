# 2026-09-20 本地剪辑工具固化

本次在现有 FFmpeg 实现上增加三个 MCP 工具与本地 CLI，供 Agent 执行高频编辑；ChatCut 暂不接入。

| 高频工作 | 落地入口 | 证据与限制 |
|---|---|---|
| 验收版选片、非破坏剪辑清单 | drama_edit_local_media | SHA256、验收依据、源帧区间、修订号；不自动推断验收 |
| 精确裁切拼接 | 同上 | 相同整数 CFR、实际 PTS 预检、视频主导时长、原声偏移保留；暂不支持 VFR/变速/J-L cut |
| 接缝检查 | 同上 | 每个剪点12连续帧与带声短片，仍须实际观看听音 |
| 中英字幕 | 同上 | 源片到时间线映射、ASS/SRT、拒绝跨剪点及重叠、边界帧预览；硬字幕状态需先核实 |
| 原声保留与补充混音 | drama_process_local_audio | 视频包直接保留，原声＋定点补充音轨、增益/淡变/限幅；不整段静音重配 |
| 响度与落点 | 同上＋接缝预览 | 区间 LUFS/true peak，完整混音与对白标签分开；落点需听看，未实现语义自动对齐/自动ducking |
| 声音母版精裁 | 同上 | 样本级裁切、原采样率/声道、PCM24、来源哈希；供应商格式另用已有参考资产工具派生 |
| 局部修订与4K复用 | drama_compare_local_edits | 精确源哈希/区间匹配，核验4K规格/帧数/文件哈希；不自动启动超分或证明视觉等价 |

合同、JSON 字段和调用示例见 `plugins/ai-drama-studio/skills/clip-studio-craft/references/local-edit-tools.md`。
输出目录必须全新；结果区分技术成功、观看、听音和用户验收。当前工具不自动写入制作数据库或替换锁定母版。

验证使用合成片，包含中文及单引号文件路径、音轨长于画面、字幕边界、错误哈希、裁切越界、拒绝重复覆盖、音频精裁与混音视频包一致性。没有调用生成模型，没有改动已封存作品。
