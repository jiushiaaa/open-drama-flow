# 用对焦、景深、机位与景别引导注意力

来源：用户2026-09-20提供的镜头语言笔记，结合已有shot-language、运镜/动作覆盖和Hell Grind方法整理。本文为创作规则与可用描述，不表示全部镜头组合已实测；只要求学习时不启动图片/视频调用。数量、风格、画幅与已接受角色约束继续优先。

## 把六个选择分开

| 选择 | 回答的问题 | 不应混同 |
|---|---|---|
| 景别 | 画面收入身体/场景多少、信息有多大 | 不是焦距或机位高度 |
| 机位 | 从哪个方向、多高、朝上或朝下看 | 仰拍不等于角色实际长高 |
| 透视/焦段意图 | 近远大小关系、空间展开或压缩 | 透视首先由相机位置决定；只变焦而不移动不会改变同一视点的透视关系 |
| 对焦 | 哪个可识别对象/部位此刻最清楚 | 不等于一定浅景深，也不是把画面裁成特写 |
| 景深 | 焦点前后多大范围可接受地清楚 | 浅景深虚化不同于运动模糊、烟雾、低画质 |
| 构图 | 人物/空间如何分配、留白有什么目的 | 不必每个单人都三分、每栋建筑都对称 |

先写“观众这一刻要读到什么”，再选择。焦点是注意力的重要线索，但运动、明暗、脸和声音也会抢注意；不能保证观众只看焦点。

## 对焦位置：必须点名对象

| 方案 | 可用描述 | 适用目的与风险 |
|---|---|---|
| 前景对焦 | 前景桌缘的唯一钥匙齿纹清楚，后方人物和门轻虚 | 道具线索、从遮挡处窥看；窥探感还需机位/遮挡，不是虚化自动产生 |
| 主体对焦 | 对焦当前说话人的近侧眼睛，面部口型清楚 | 对话、微表情；若手中物才是关键信息，改锁手物，不机械一直锁脸 |
| 背景对焦 | 远处门口的人影轮廓清楚，前景肩膀柔虚 | 信息揭露、悬念、人物观察目标；避免无意提前暴露剧情信息 |
| 有动机拉焦 | 他看向门口后，焦点由前景手中的物件移到门口来人；机位保持 | 注意力跨层转移；写起点、触发、终点及落定，不能只说“自动电影拉焦” |

拉焦是一种随时间变化的控制，前景/主体/背景对焦是当前状态。静态图只写某一时刻的状态；视频再写转移过程。拉焦引起的清晰变化不是相机平移产生的视差。

## 景深按需要可见的信息选择

- 浅景深：焦点附近窄范围清楚，前后逐渐柔化；主体不在同一焦平面时，不要求双眼、远手和身后人物同时锐利。适合单个情绪/道具焦点，不能糊掉需要验证的攻击者、接触点与受力者。
- 中等景深：主角及附近交互对象可读，背景层次略柔但布局可辨。对话、拿取东西等常用起点，不是固定所有文戏的默认值。
- 深景深：前中后关键对象和地面关系清楚，适合定场、群像、走位或动作关系。不是无限远与镜头前任意近物必然都锐利，远近尺度也决定细节是否可辨。

景深还受对焦距离、光圈、焦距与成像尺度影响。生成提示词优先写清楚/柔化对象，光圈数值仅作视觉意图；模型文本不等于实际相机光学设置。不要用虚化遮掩NPC/道具材质偏写实。

## 机位角度

- 平视：相机约在当前主体眼睛高度，适合平等交流、清楚观察。坐下或站起后高度关系应重新说明，不是永远固定一个绝对高度。
- 约45°俯拍：机位在主体上方斜向下，看得到桌面和物体前侧层次；适合桌面操作、食物或空间布局。不要与正顶90°鸟瞰混用。45°是意图，输出需看实际效果。
- 仰拍：相机低于主体朝上，可强化体量和压迫。先用已接受的身体比例与同框尺度表达高大，再选自然透视低机位；避免贴脸超广角造成头小身膨、腿过长。

角度与情绪不是一一对应：俯拍不一定弱小，仰拍不一定英雄。按当前叙事与观众位置选择，也不要全片固定侧面。

## 景别命名与可观察裁切

不同资料的中文叫法有差异，生成前以可见边界为准。

| 约定叫法 | 英文辅助词 | 画面边界与作用 |
|---|---|---|
| 大远景/远景 | extreme wide / wide establishing shot | 环境主导，人物很小；交代在哪里，通常看不清微表情 |
| 全景 | full-body / full shot | 完整头顶到鞋底，保留脚下地面和动作余量；走位、落脚、多人关系 |
| 中远景/膝上景 | medium-long / knee-up shot | 膝盖以上，读上身动作与部分环境；**看不到鞋底与完整脚步，不可验收落地** |
| 中景 | medium / waist-up shot | 常以腰部以上为约定；手部动作要另确认有没有入框 |
| 中近景 | medium close-up / chest-up | 胸部以上，读表情和对白，环境按意图保持可辨或虚化 |
| 近脸特写 | close-up | 面部或某局部占主导，裁切明确；可配中/浅景深，不必全部糊背景 |
| 大特写/细节 | extreme close-up | 眼、指尖、物件局部等；需要仍可辨认的形状与空间来源 |

“无人机超广角”是平台/机位＋镜头透视的组合，不是景别。需补大远景/全景与运动路径。约12mm只表达极广角感；远处高空无人机不一定出现强烈近大远小，必须有近景物和相应视点。不要让超广角重新拉宽人物。

“微距”是近距离高放大倍率拍摄方式，可产生细节特写；不是所有特写都是微距，也不是所有微距都必须1:1。几厘米、12mm或1:1都不能当模型已兑现的物理精度。

## 构图有理由再用

- 对称：强调建筑秩序、轴线、倒影或对峙；先确认场景实际有对称依据。倒影不是任意复制人物，多镜后地标仍相同。
- 左右三分：为人物视线/移动方向、文字或环境信息留空间；不要把脸放边缘后又让视线撞出画外。居中、留白和不对称也可按情绪成立。
- 过肩：明确近处肩膀属于听话人，远处脸是说话人，保持轴线和视线目标。前景肩只占小部分并稍虚，不能挡住说话人的嘴、双手关键动作，也不能凭空多出一人。

## 组合示例（方法模板，非第三集拍摄脚本）

**平等对话**：平视胸上中近景，说话人位于画面右三分之一，看向左前方听话人；前景左缘是听话人的肩，稍虚；对焦说话人的近侧眼睛，中等景深，房间主要布局仍能辨认，口型清楚。同轴反打明确双方身份。

**道具先行的悬念**：前景桌上唯一钥匙特写，对焦齿纹，浅景深；后方门口暂时模糊。听到开门声，持物人视线移向门口后再拉焦到来人；不改变人物位置，不复制钥匙。对白/声桥只作为触发，不自动生成无关闪回。

**交代行动空间**：同侧平视双人全景，完整鞋底和脚下地面入画，中到深景深，两人和接触区域都清楚；地标说明可移动路径。此模板是规划原则，不能把此前裁脚失败记成通过。

**高大人物出场**：轻微低机位全身或膝上景（按所需动作择一），自然透视，脸和肩身比例保持，利用同框他人/门框形成尺度关系；不要用短焦贴近制造失真的“高大”。

**看清桌面操作**：约45°俯拍，中等景深，焦点在拿起杯子的手和杯口，桌面关系可辨，背景不抢戏；若需确认人脸身份先建立人物镜头，再切手部。

## 每镜可执行记录

`观众关注点 → 景别/裁切边界 → 相机高度/朝向 → 透视意图 → 对焦对象/何时变 → 清晰范围 → 构图理由 → 必须可见的动作 → 结尾状态`

写入现有ShotSpec：camera.shotSize=景别及边界；camera.angle=机位；camera.relation=焦点对象、清晰层和构图关系；camera.movement/speed=真实运镜；imagePrompt描述静态状态，videoPrompt/motion.timing描述有动机的拉焦；qualityRisks列嘴部被挡、脚出画、焦点漂移等。不要往provider参数硬塞未支持的focus/aperture字段。

相邻镜头不重复同一种机位仅为省事，也不为展示技巧强制换角度。沿前镜实际状态选择下一镜主信息，检查轴线、目光、焦点、接触、画幅和全画面材质。

## 证据与待验边界

既有技能已记录平视/低机位/过肩、视差/焦点接力、多机位覆盖；第二集历史多机位实验有拉焦占据动作时长和近景停姿，删除长拉焦后仍停姿，因此不能把拉焦当唯一失败原因。已有记录不等于本页每种组合都有独立成功样本。

本轮只做概念校正、组合模板和资料整合，不生成新媒体。短攻防与旧方法复测按用户要求暂停；需要正式镜头时按当时授权应用已有规则，实际生成后再查焦点是否落对、关键动作是否可见，不用提示词存在代替验收。
