# 有动机的灯光、人物调度和摄影机路线

来源：用户2026-09-20转述的短视频创作笔记，经项目重写。未收到原视频/完整提示词，未做本批生成实验；以下为规划方法，不是模型成功率承诺。景别、焦点与景深沿用 [取景规则](focus-depth-framing.md)，不重复建立相互冲突的命名表。

## 镜头先有任务

先写观众在镜头结束时新增的认识、情绪变化或尚未获知的信息，再选择景别、角度、人物行为与光线。任务可以是维持紧张、等待反应，不必每次移动都揭露新物件。
远景偏环境、全景偏空间关系、中景兼顾状态与动作、近景偏细节情绪是选择线索，不是公式。平视不必然中立，低机位不必然英雄，高机位不必然弱小；POV是视点归属，不是机位高度，荷兰角是画面滚转，不是另一种俯仰。
同一主体可包含互动双方，一个叙事任务不等于只准出现一个人。动作接触需要同时看见施力者、目标和应对时，不强制特写单人。

## 六类灯光：用光源关系描述

| 光型 | 可观察的提示词 | 情绪用途与条件 |
|---|---|---|
| 顶光 | 天花板固定小灯从正上方照下，眉骨和下颌留下清晰阴影；或大面积顶棚漫射光形成软阴影 | 硬顶光可突出压迫，柔顶光可突出孤立或仪式；由空间、表演和构图共同决定 |
| 侧光 | 窗在角色右侧，朝窗侧脸和衣纹受光，背窗侧保留可辨暗部，转头时明暗边界沿面部移动 | 纹理、生活感、犹疑或隐瞒；对白嘴部和角色辨识度不能被暗部吞没 |
| 逆光 | 后方夕阳勾出发缘和肩线，前方墙面反射少量补光；背后灯具的位置不随人移动 | 轮廓分离、浪漫或威胁均可能；禁止高光溢出抹掉五官或把肤色改变当成新身份 |
| 伦勃朗光 | 前侧上方主光，背光侧脸颊保留小三角亮区，其余暗部有层次 | 可用于克制的肖像、严肃对话；不是在任何转头角度都贴着脸保持不动的三角纹样 |
| 体积光 | 后侧窗光穿过稀薄尘埃形成局部光束，人物和主要动线仍清楚 | 空间纵深、注意力引导；不必有光束，不能堆浓烟遮掉接触或镜头衔接 |
| 底光 | 下方篝火随火苗轻微变化，或手持灯从下方照脸；写清补光来源 | 暖底光也能诡异，冷底光也不必然恐怖，依行为与环境判断 |

模板：`实际光源/场景地标 → 世界方位与高度 → 相对主体方向 → 软硬与强弱 → 补光/反射 → 动作经过时的变化 → 观众感受`。
光型方向、光质软硬、颜色、强弱分开写。灯光重要，但不能断言它在所有作品中比画质、表演、调度更重要。

例：门右上方的暖灯固定不动，来人从门口走向桌边，近门肩部先亮后暗，脸离开灯区时由室内柔和反射维持可辨；手绘三渲二的色块、线条、衣料与NPC材质保持一致。避免自动贴脸补光、自动曝光抽动及借暗部掩饰换脸。
拍角色母卡时优先中性、均匀、便于辨认的光照；上述情绪灯光用于剧情镜头，不能把色光污染固化成角色肤色。

## 固定世界，允许画面方向变化

1. 给角色编号并绑定当前参考版本和稳定身份。编号是编排标签，不是能锁住身份的模型私有参数。
2. 区分世界地标、人物身体左右、屏幕左右。固定入口A、桌区B、走廊C及相连关系；相机绕行后入口可以转到画面后方，不能强制“入口永远在屏幕前”。
3. 记录角色间持续关系：02领先01半步，03位于04右后方且不越过她；关系因剧情改变时写明触发和路径。距离数值是意图，需要成片复核。
4. 记录相机归属、离地高度、距主体大致距离、起点/终点、视线目标、可通行路线。真实距离要与走速和时长相容，避免拥挤空间中不可能的穿越。
5. 关键动作保留完整因果：下车→关门→步行靠近→汇合；取物→持物→移交/放下→空手。不得由遮挡后突然换状态。
6. NPC按区域和职责安排少量不同节奏：一人观察、一人低声交谈、一人短时静止。不要要求全部持续运动或同时转头，不复制主角发型服装充当小弟。

不要求每个新场景先生成场景图，但同一场戏必须保持空间拓扑。场景图/文字布局都只是约束手段；文字不会保证隐藏空间准确。一次性布景不升级为第三集永久场景母版。

## 运镜记录：触发—路线—信息—落定

| 手段 | 必须写出的具体变化 |
|---|---|
| 推近 | 起止景别、靠近谁、为何靠近；说明机位前进还是变焦 |
| 拉远 | 拉远后新增的空间关系；若只是情绪留白，也写明目的 |
| 横移 | 相机横移路线、前后景视差、谁留在画内；不是原地摇头 |
| 跟拍 | 人物行进方向、领先或跟随关系、相机在前/后/侧、速度变化 |
| 环绕 | 旋转中心、幅度、何时看见谁、是否越轴、终点朝向；不默认整圈 |
| 摇镜 | 固定机位转向，从对象A到对象B；由声音/眼神触发后落定 |
| 手持 | 身体/步伐来源、幅度和收稳时间；避免随机滤镜抖动 |
| 静止 | 用人物进出、目光、呼吸或前后景变化推进；允许完全静止的情绪停顿 |

复杂相机可用虚拟无人机描述路线，但不把惯性、偏航、俯仰、升降同时堆进每镜。手持观察者、轨道摄影机和无人机是不同的运动模型，选适合当前镜头的一个。
提前/滞后跟随、短时遮挡、运动后的短失焦可提供拍摄感，但不能遮住开口者、招式命中和道具转移。清楚叙事优先，不为“呼吸感”强制加失焦。

## POV是角色在看

先绑定是哪位角色的眼睛，再写听见/看见的触发、转头、呼吸、步伐、让路和恢复视线。紧张可表现为浅快呼吸、肩颈紧、步幅缩短，不随意改成停止前进或改变剧情任务。
只展现角色当下能看到的范围；遮挡后的目标不可凭空透视。角色的手、鞋和合理反射可以入画，不能无因切成外部无人机视角或正脸。
正向指令搭配少量针对性约束：真实落脚造成轻微起伏、停步后收稳；避免持续机械抖动。负向约束是提示文本，不假定当前接口支持单独negative_prompt字段。

## 长镜头按事件拆分，不按术语堆砌

规划表每行：`阶段/时间预算｜角色状态与位置｜触发｜摄影机路线及观察目标｜本段允许揭露的信息｜必须保留的画外信息｜段末状态`。
例（通用示范，不是第三集剧情）：观察者走向入口→听车门声回头→镜头沿视线看到同伴下车关门→同伴走来会合→两人通过入口→一人停下观察画外物体，另一人晚半拍注意到。全程检查空间、时长和动作余量，不把所有事件强塞进固定24秒。
需要悬念时结束在反应，不展示目标；需要明确解答时展示目标。此手法不能成为每场戏都不给答案的套路。

## 编译和审核

沿用现有ShotSpec和当前provider支持字段：camera记录景别/角度/路线，动作时间线描述触发与状态；主光源、地标、光照变化写入静态/视频提示词或现有描述字段，不新增虚构光学参数。
先列“参考图/原片已提供什么、必须延续什么、这次新变化什么”，再写缺失信息。字幕、音色、画幅仍按当前项目合同。
逐阶段看实际画面：说话人嘴和目光是否对应、灯是否留在世界里、人物数量是否稳定、脚步/取放物是否完整、镜头是否及时揭示且未提前泄露、最后一帧能否承接下一段。已暂停的实验继续暂停，规划采纳不等于实测通过。
