# 风格与特效

出版说明：以下方法来自本项目的重写整理。实验编号、覆盖数量及复盘是研究快照，不是当前环境实测；`<private-project>`、`<private-source>` 和未链接的研究文件仅为可选私有证据索引，不随插件分发，也不是运行依赖。没有对应证据时只采用待验证的方法，不宣称复验通过。

## 元素差异应超出换色

从 `发起点 → 运动机制 → 作用目标 → 目标变化 → 残留与退场` 设计一个清楚的效果。先测试一条机制，不在短片里同时塞多次清场、首领战和天地异象。

| 元素方向 | 可供设计的差异 | 必须观察的证据 |
|---|---|---|
| 冰 | 霜纹扩散、透明棱晶生长、脆裂 | 生长从哪里开始，目标如何被包覆，碎片留下在哪里 |
| 火 | 流动火舌、附着燃烧、热扰动、余烬 | 火焰是否沿路径抵达目标，退场后是否留下焦痕 |
| 水 | 流动、绕障、涡旋与湿润残留 | 水体连通性、流向与积水结果 |
| 土岩 | 断层抬升、重量与坠落、结构破坏 | 地形如何变化，碎块如何落地 |
| 雷 | 分叉路径、短促放电、灼痕 | 发起与落点是否关联，亮光是否遮蔽动作 |
| 风 | 用尘、布料、叶片表现气流 | 周边物沿同一流向响应，而非只多一层光圈 |
| 光/暗 | 照亮或遮断、区域边界与显隐 | 主体轮廓和空间仍可辨，不把黑屏/白屏当成功 |
| 飞剑 | 有数目与方向的实体轨迹 | 武器数量、握持/离手、回收是否连贯 |

这是从来源词库重新组织的设计选项，不是物理定律，也不是每个方向都已实测。F03/F04 探索冰与火的路径、材质和残留；F07 增加风切布旗实验。F07 抽帧可见横向断裂、下片落地和破损保留，但风路不够清楚，准备动作偏长，结果保持时间不足；完整播放尚未完成，不能整体标为通过。其他组合逐次取用时继续验证。

把特效的成功拆成不同观察项：看见目标断裂，不等于看见了发起点到目标的连续路径；有残留，不等于残留时长达标。不可见的气流可借叶片、尘线、布料依次受力显示，但不能把这些载体的随机运动当成受控轨迹。刀光或剑光也要分清实体刃、短暂拖尾和接触闪光，分别检查数量、握持连接与退场。

能力尺度服从世界观和已批准角色。普通近战不自动升级为毁城；失败方不必死、首领不必出现、末镜不必白闪收黑。特效应帮助读动作，并在下一招前按需要退场。

## 复古秩序构图

取用水平构图、成对/成排布景、明确色板、真实旧材质和克制小动作。秩序可以来自左右平衡、框中框或纵深，不强迫所有人物站正中央。

中轴由构图关系形成，不在脸前画一根中线。前台员认真摆正信封这类小动作可带来冷幽默；不要为凑道具数量堆满画面。复古颗粒不等于发灰或脏雾。

这是可选的实验风格，不覆盖项目已批准画风。使用具体视觉特征，不声称复刻某位创作者的完整审美，也不自动增加外部角色、广告签名或品牌。

## 清透动画氛围

优先设计近景遮挡/滴水、中景人物或道具、远景天空建筑，明确主光方向、天气时段与冷暖关系。若要视差，安排能看清的前中后景与简单相机位移；背景有三层不代表实际生成了视差。

环境细节服务人物的发现或等待：雨滴落点、伞的开合、视线方向应互相联系。保留时间一致和衣着身份，不自动套日本校服、东京、神秘少女或半片旁白。

源资料的“某导演永不居中/不用对白/只用纯音乐”等绝对描述未获核实，剔除。天空占比、饱和度、逆光强度按情节调整，不当作所有动画的强制模板。

## 负面提示不能删除创作目标

先核对当前接口是否有独立负面字段，以及它如何参与实际请求。源库按模型划分的语言偏好、词数上限和“首句权重最高”不作为未经验证的运行时事实。

只针对本镜实际风险描述排除项。拳击落空、角色交叉换位、背景被遮挡、头部转向、风格化拉伸都可能是预期动作；不能把“不接触”“位置变化”“脸不对称”无差别禁掉。我们的 3D2D 画风也不能同时继承“禁止2D”和“禁止3D”。

动作线、半调网点、胶片颗粒、场内招牌或有意景深模糊是否保留，取决于任务；不因它们出现在通用负面库就自动移除。提示里堆多个渲染器和“8K”既不代表实际使用那些引擎，也不改变输出分辨率。
