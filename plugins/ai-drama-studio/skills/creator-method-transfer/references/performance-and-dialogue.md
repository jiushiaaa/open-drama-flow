# 表演与台词

出版说明：以下方法来自本项目的重写整理。实验编号、覆盖数量及复盘是研究快照，不是当前环境实测；`<private-project>`、`<private-source>` 和未链接的研究文件仅为可选私有证据索引，不随插件分发，也不是运行依赖。没有对应证据时只采用待验证的方法，不宣称复验通过。

## 两条线同时成立

先确定外部任务：折信、驾驶、守卫、递物等，以及不能改变的手部动作、道具和视线关系。再写内部情绪如何受一个可见事件触发。

可用结构：平静维持 → 察觉触发 → 试着压回 → 少量情绪泄露 → 继续完成任务。

复杂表演允许再一次恢复和反弹，但不要把过多状态塞进几秒。每阶段选 1–3 个能看见的变化；眼神、呼吸、嘴角不必同时全动。强度分档是作者的沟通工具，不是模型 API 参数。

悲伤不自动意味着捂脸、放下物品、停车、转身或低头离开画面。若外部任务必须持续，就检查结果中是否真在持续。情绪词增加了而任务停止了，不能算双线表演通过。

关系视线应有对象。短暂移开后是否回到对方、照片或手上的工作，必须能从动作理解。新情绪保留旧情绪的痕迹，避免突然换脸。

## 完整对白优先

用户提供的台词、独白和长篇议论原文保留。时长不够时先计算和试读，再调整镜头数、段落时长与画面，不擅自改成短旁白或换词。

字数除以估计语速只能给粗略时长；方言、停顿、重音和表演会改变结果。最终以实际配音/原声和核对文本为准。源资料“正常 3.5 字/秒”与另一处“2.5–3 字/秒”互相不同，不采用统一硬阈值。

源资料的例子把 50 字改为两段 25+22 字，既漏了 3 字，也超过其自己给定的 8 秒/7 秒字数上限。任何自动拆分都必须核对串接后的完整文本与原文相等。

台词可以跨反应镜头延续，是否切镜由叙事和声音连续性决定；不强制一句话一镜、每句都拍说话者、全场 6–10 轮短句。

## 时序与声音

生成提示可优先用语义节拍；制作表和剪辑表仍可有时间码，但要标明预估。L04 的精确阶段秒数未全部兑现，不能说改成语义节拍一定更好；F02 为不同场景的探索样本，不是严格对照实验。

有对白或音效目标时单独核验音轨、实际听音和声画同步。静音视频只验证可见表演，不能据此宣称哽咽、气息或对白声音已经成功。

选择动作音时说明鞋/地面或武器/目标的材质、距离、力度、衰减与对应事件。环境声记录空间来源；配乐与场内可听见的音乐分别处理。用户要求完全无音乐时，不能暗加街头吉他或隔墙夜店乐。

源库的“台词100%、动作70–80%”“关键声音放大十倍”“静音0.3秒冲击翻倍”不是可复核混音标准。不直接转成固定增益，先保留可懂度、检查峰值与听感；命中同步逐事件核对，不能仅看计划时间码。所有法术都必须蓄力音、每集只准三次静默等配额均不继承。

“热血且阴郁”“喜剧且悬疑”可以是有意的复合情绪，不因命中两个词就自动暂停或要求二选一。先确定当前节拍的主情绪以及希望观众发生的感受变化，再选表演、构图和声音。
