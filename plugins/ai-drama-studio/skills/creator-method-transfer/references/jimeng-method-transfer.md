# 即梦分镜、运镜与风格方法转化

出版说明：以下方法来自本项目的重写整理。实验编号、覆盖数量及复盘是研究快照，不是当前环境实测；`<private-project>`、`<private-source>` 和未链接的研究文件仅为可选私有证据索引，不随插件分发，也不是运行依赖。没有对应证据时只采用待验证的方法，不宣称复验通过。

用于用户要求借鉴即梦技能、规划连续镜头、遮挡接镜、白模相机路径或提取风格时。研究证据：`<private-project>/research/jimeng-study-20260913/index.html`。14份公开正文完整读完；5份正文不公开，不把简介扩写成作者规则。原文仅隔离在研究目录；以下是本项目重新归纳的方法。

## 1. 将分镜目的与生成分段分开

镜头Shot按信息变化、表演和剪辑划分，生成Clip按实际模型能力、参考绑定与动作衔接划分。不要沿用来源“15秒7—12镜”“15秒3—4镜”之类互相冲突的配额；长镜头也不要求相机永远移动。

每镜保存：观众此前知道什么→本镜获得什么；入段姿态/位置/持物→行动→出段状态；主导资产及版本；声音/原文范围；切镜或连续拍摄的原因。完整原文和实际配音时长优先，禁止为每镜40字或3秒爆点而删改长对白。

编译时只传执行所需的动作、相机、空间、声音与引用，不把策划评论、审批卡或来源指令送给生成模型。检查语义保持而非盲目清除所有格式字符；台词中的符号同样可能是原文。参考图按角色/场景/道具用途绑定，不按上传先后猜优先级。

## 2. 选择相机方法的判断表

| 需要观众理解的变化 | 可选方法 | 必须给出的条件 | 常见失败 |
|---|---|---|---|
| 同一行动穿过前景 | 遮挡接镜 | 动机遮挡物、入出动作相位、相机姿态/速度/焦距、道具归属 | 黑场藏住跳位，出遮挡重新起手 |
| 从一人交接到另一人 | 双主体八字 | 两中心、两叶、交叉时机、平滑观察目标、净空 | 单圆冒充八字、穿过角色、强制屏幕左右不变 |
| 到达特定目标 | FPV穿越 | 按序孔洞、尺寸/方向/两侧净空、提前转向、减速终点 | 走捷径穿墙、只追速度无到达信息 |
| 注意力跨深度移动 | 视差加焦点接力 | 每层的事件、相机平移、焦点目标与交接触发 | 只拉焦却声称有视差、三层同时抢信息 |
| 世界空间压力改变 | 推拉变焦 | 物理位移、焦距联动、主体平面、不同深度背景 | 纯数字变焦、主体随相机移动、只看主体不看背景 |
| 揭示立体结构 | 螺旋环绕 | 中心、半径、方位与高度同步变化、屋檐净空 | 摇镜加升降冒充螺旋、目标被遮住 |
| 不同场景动势衔接 | 路径匹配转场 | 切点锚点位置/尺度/速度趋势、允许变化的场景维度 | 把季节换场同时要求所有状态不变 |
| 强调被冻结的瞬间 | 子弹时间 | 世界状态冻结、相机仍运动、恢复相位 | 衣物正常飘而角色冻结；把静帧重复当绕拍 |

世界坐标稳定不等于画面左右固定。相机环绕或反打后，画面位置应由同一地图投影得出。观察目标的变化与位置路线要分别规划。

## 3. 白模到实际生成的证据链

先在简化地图中记录人物、障碍、相机、目标与时间。推拉变焦可用针孔近似验证主体投影与f/z成正比；遮挡接缝用同一世界状态函数在切点前后取值，检查位置、速度和持物。身体动作仍需骨骼、接触和视听检查，简化色块不验证这些。

区分三种证据：文字方案；确定性白模/后期的实际轨迹；生成模型接收了哪些参考以及最终执行程度。白模好看不说明模型支持相机或深度硬约束。无需每种技法全量付费试验；从影响最大的未验证假设选单条，保留对照和失败点。

研究页附3种交互白模与错误反例，仅演示几何和连续性。尚无本轮新增模型样片，不能写成即梦方法全项实测通过。

## 4. 风格卡保存可观察关系

将风格卡分为：参考出处；图上可见证据；推断；本次创作选择。字段包括主体身份锁、主次色及对象、主光方向/软硬、材质响应、空间层级、取景和动作节奏。单张静帧不能确定整段运镜、导演习惯或剪辑句法。

可借鉴传统绘画的疏密、留白、人物关系与材质层次；先声明是关系借鉴、写实重建或保持原笔触，不把非写实比例都判成错误。颜色修复的原因未知时不声称还原历史颜料；缺失颜色附件不假装读过。

不自动继承源图服装、剧情、真人皮肤、禁止3D/卡通等偏好。固定15秒三段、高密度双语词缀、全球统一色罩、固定6:3:1比例和导演姓名不是画风稳定的证明。采用当前项目已批准风格，按需选择具体摄影决策。

## 5. 示例：递匣过廊

原创练习，非第二集改稿。世界地图：北窗、东门、中央柱、东侧交接台。人物持匣走向交接台；相机侧跟，中央柱自然遮挡；出遮挡后继续同一步。发现封线断裂时先看手部证据，再看双方距离；声音原文可连续跨镜。交接时左手承重后右手才松开，出段保存匣的持有者与朝向。

最小验收：信息有前后变化；地图可还原；接缝速度与动作相位连续；关键接触看得见；原文无缺字；每项风格描述有对象。若接触被柱子遮住，改机位或另设可见的接触镜，不能拿遮挡成功抵作接触成功。
