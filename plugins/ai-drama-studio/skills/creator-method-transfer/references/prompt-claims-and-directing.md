# 导演方法与技术宣传分开记录

来源：用户2026-09-20提供的博主文字摘要；没有原视频、完整请求或对照成片。本页不声称观看了假面骑士、加冕或刑侦长镜头案例，也不默认安装LibTV/Topaz。

## 可采用的工作方法

- 用主体/动作、环境/光影、相机/光学、时间/状态、视觉介质五个栏目检查缺项；这是制片检查表，不是模型内部五维坐标系统。
- 先写任务，再写可见动作、取景、光源与结尾状态；把“害怕”落实成短促吸气、补步等行为，把“电影感”拆成可观察条件。
- 参考内容已明确时，减少重复与冲突，集中描述本次变化；同时保留易漂移的脸、体型、衣物状态、道具数量等必要约束。
- 精简相互竞争的事件，不机械限制字数。精确动作描述可以较长，短提示词也可能矛盾。时间分段是计划，不保证模型逐秒执行。
- 用先后因果和日常动作描述提高可读性，必要时专业术语搭配可见结果；不笼统禁止物理术语。
- 看参考的首尾和转折帧，配合正常速度播放及声音，反推主光源、人物相对关系和信息揭露时刻。现有抽帧/接缝工具已可提供证据，不依赖某个博主推荐平台。

## 不迁入项目事实的说法

| 宣传或简化说法 | 项目采用的表述 |
|---|---|
| 提示词可精准分配交叉注意力权重 | 文本会影响生成，但当前接口没有可验证的逐对象内部权重控制 |
| 素材锁定四维后100%算力用于运镜 | 减少变化因素可能让请求更清楚；没有算力分配证据，不能量化承诺 |
| 景别决定底层算力分配 | 景别决定观众看到的信息范围，不等于已知模型硬件/注意力调度 |
| same character / consistent location精确锁住人物空间 | 需要真实绑定参考、版本、地标和成片检查，文本不是身份保证 |
| 先超分就能避免模型把模糊当风格 | 只在确有可读性问题时考虑修复；超分可能补造五官/纹理，修复版必须与原参考比对，不强制做前置步骤 |
| 所有镜头必须运动以免静态 | 静止镜头和停顿都可承载叙事；根据任务选择 |

研究依据：[DiTCtrl](https://arxiv.org/abs/2412.18597)研究的是模型级注意力操作与多提示词视频控制，并不证明普通商业接口文本可精确分配算力。[Sora研究报告](https://openai.com/index/video-generation-models-as-world-simulators/)讨论时空patch、扩散和交互局限；其架构不能直接推定Seedance架构。这些来源只支持证据边界，不能替代当前模型实测。
