# IP 潮玩六宫格动态海报：完整制作工作流

> 本工作流由 OpenDramaFlow 总控调度，默认按 Seedance 2.5 当前适配器执行。

## 运行时合同

- 总控优先：必须完整阅读[总控执行规则](../ai-drama-producer/references/execution-contract.md)。默认 automatic，在用户目标与冻结上限内自动规划、自检和执行；专业阶段的方案/提示词确认不另设人工关卡，除非用户要求或当前为 manual。只要求提示词时不得启动生成。
- 图片：必须先阅读[图片生成与用户验收入库合同](../ai-drama-producer/references/image-asset-contract.md)。默认 Codex 内置图片工具（image2）生成库外候选，展示并经用户验收后才入库／完成任务；仅内置不可用、失败或用户明确要求时使用项目图片模型。自动执行不等于图片验收，也不等于批准生产记忆。
- 视频：Seedance 2.5 使用 `drama_request_paid_batch` 冻结请求，再用 `drama_authorize_and_start_paid_batch` 按当前策略启动；`drama_resume_paid_batch` 只恢复原有 waiting 任务。automatic 不弹产品审批框，manual 才要求可信确认，宿主权限独立。
- 提示词：必须阅读[Seedance 专业指南](../ai-drama-producer/references/seedance-prompting.md)，用当前能力与 ShotSpec 编译请求。参数由当前适配器校验，不继承其他供应商字段或强制节点流程。
- 声音：ASR 与标准音色 TTS 已接入，先查 `drama_get_capabilities`；没有语音 Key 时使用 Seedance 原生声音并实际听音检查。声音克隆、独立音乐生成、3D 编辑器与剪辑软件工程写入尚未接入，不伪造结果。
- 项目与资产：用 `drama_get_state` 读取事实、`drama_update_plan` 保存实际方案；稳定 assetId 与版本不随文件夹路径变化，本地路径不能直接充当供应商 URL。
- 完成：FFmpeg 用于确定性剪辑；生成/下载/探针成功不是交付。按总控检查实际画面、运动、对白、音轨与字幕，记录质量审核后才完成交付。

# IP 潮玩六宫格动态海报

使用本 Skill 将用户上传的 IP 角色转化为竖版潮玩六宫格动态海报。标准流程只有两步：

1. 根据用户 IP 图，基于原始生图模板生成一张 9:16 不规则圆角六宫格静态海报。
2. 使用该静态海报作为参考，基于原始视频模板生成一条 6 秒竖版动态海报视频。

本 Skill 的重点是**提示词保真**：不要自由重写用户原始提示词结构，只能按 `references/prompt-fidelity-rules.cn.md` 做最小必要替换。

## 文本模板资源

本 Skill 不使用内置参考图片。所有执行依据来自以下文本模板：

- `references/static-six-grid-prompt-template.cn.md`：STEP 1 静态六宫格生图主模板。
- `references/motion-six-grid-prompt-template.cn.md`：STEP 2 六宫格视频主模板。
- `references/prompt-fidelity-rules.cn.md`：提示词保真和最小替换规则。

运行时必须读取对应模板文件，不能凭 Skill 正文自由改写成另一套提示词。

## 必需输入

用户必须提供：

- 一张 IP 角色 / 吉祥物 / 原创角色图片。

可选输入：

- 角色名或品牌名；
- 是否需要文字标题，默认不加文字；
- 音乐或音频参考，默认没有真实音频，只按假想音乐节奏设计动作；
- 最终时长，默认 6 秒；
- 输出比例，默认 9:16。

如果用户触发本 Skill 但没有上传 IP 图，先要求用户上传 IP 图再生成。

## STEP 1：静态六宫格潮玩海报

1. 先分析用户上传的 IP 图，提取必要的非颜色身份特征：轮廓、物种与身体结构、身体覆盖状态、身体表面材质、面部结构、头部造型、参考图已有服装或配饰、标志性道具、特殊纹样和整体气质。
2. 读取 `references/prompt-fidelity-rules.cn.md`。
3. 读取 `references/static-six-grid-prompt-template.cn.md`。
4. 以该模板作为主提示词，只进行最小替换：
   - 把“参考图中的角色”绑定为用户上传的 IP 角色；
   - 在“角色统一要求”后补入必要身份观察，必须包含身体覆盖状态；
   - 如果参考图角色没有穿着服装，最终提示词必须保持未穿服装状态并禁止添加衣服、袖口、鞋帽等人类服装；
   - 先判断用户上传参考图的背景色，把 `【参考图背景单色】` 编译成具体颜色词，例如“纯白色背景下”；
   - 最终生图提示词里不要保留“根据用户上传参考图来决定”这类判断依据；
   - 仅在冲突时替换道具或其他颜色；
   - 不改布局、宫格编号、比例、圆角规则、黑底间隔和负面要求。
5. 使用最终模板提示词生成 9:16 静态六宫格海报。

生成后如出现以下问题，应先重试或让用户确认，不要直接进入视频：

- 宫格数量错误；
- 布局变成平均网格或标准矩阵；
- 圆角不统一；
- 多个宫格里的角色身份不一致；
- 宫格2出现按键或不是正方形播放器；
- 宫格6露出头部或完整脸。

如果第一步六宫格直接生成多次失败，启用精细兜底模式：先基于同一个 IP 锚点生成六张单格图，再合成为固定六宫格布局，最后进入视频生成。

## STEP 2：六宫格动态海报视频

1. 使用 STEP 1 生成的静态六宫格海报作为参考图。
2. 读取 `references/prompt-fidelity-rules.cn.md`。
3. 读取 `references/motion-six-grid-prompt-template.cn.md`。
4. 以该模板作为主视频提示词，只进行最小替换：
   - 把“参考图”绑定为 STEP 1 静态海报；
   - 保留“0-2 秒宫格4全屏开场”；
   - 保留“2-3 秒宫格4缩小归位，其他宫格飞入”；
   - 保留“3-6 秒稳定六宫格动态”；
   - 保留六个宫格的动态要求和统一负面要求。
5. 生成 9:16 竖版视频，默认总时长 6 秒。

如果视频模型无法一次稳定完成“三段式时间线”，使用简化兜底：

1. 使用 STEP 1 静态六宫格图作为锁定首帧 / 视觉参考；
2. 只生成 3–6 秒的稳定六宫格动态海报，不做全屏开场和飞入转场；
3. 如果每格动作仍然互相串格，则分别生成六个短视频，再合成回固定六宫格布局。

## 交付

交付静态六宫格海报和最终动态海报视频。如果同一轮生成多个资产，应使用简洁标签如 `IP潮玩六宫格` 进行分组。
