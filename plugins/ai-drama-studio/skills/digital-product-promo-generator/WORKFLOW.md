# 数字产品宣传片：完整制作工作流

> 本工作流由 OpenDramaFlow 总控调度，默认按 Seedance 2.5 当前适配器执行。

## 运行时合同

- 总控优先：必须完整阅读[总控执行规则](../ai-drama-producer/references/execution-contract.md)。默认 automatic，在用户目标与冻结上限内自动规划、自检和执行；专业阶段的方案/提示词确认不另设人工关卡，除非用户要求或当前为 manual。只要求提示词时不得启动生成。
- 图片：必须先阅读[图片生成与用户验收入库合同](../ai-drama-producer/references/image-asset-contract.md)。默认 Codex 内置图片工具（image2）生成库外候选，展示并经用户验收后才入库／完成任务；仅内置不可用、失败或用户明确要求时使用项目图片模型。自动执行不等于图片验收，也不等于批准生产记忆。
- 视频：Seedance 2.5 使用 `drama_request_paid_batch` 冻结请求，再用 `drama_authorize_and_start_paid_batch` 按当前策略启动；`drama_resume_paid_batch` 只恢复原有 waiting 任务。automatic 不弹产品审批框，manual 才要求可信确认，宿主权限独立。
- 提示词：必须阅读[Seedance 专业指南](../ai-drama-producer/references/seedance-prompting.md)，用当前能力与 ShotSpec 编译请求。参数由当前适配器校验，不继承其他供应商字段或强制节点流程。
- 声音：ASR 与标准音色 TTS 已接入，先查 `drama_get_capabilities`；没有语音 Key 时使用 Seedance 原生声音并实际听音检查。声音克隆、独立音乐生成、3D 编辑器与剪辑软件工程写入尚未接入，不伪造结果。
- 项目与资产：用 `drama_get_state` 读取事实、`drama_update_plan` 保存实际方案；稳定 assetId 与版本不随文件夹路径变化，本地路径不能直接充当供应商 URL。
- 完成：FFmpeg 用于确定性剪辑；生成/下载/探针成功不是交付。按总控检查实际画面、运动、对白、音轨与字幕，记录质量审核后才完成交付。

# Video Shotcraft

使用本 Skill 将真实产品、网页、前端项目或用户提供的动效参考转化为完整产品宣传片，使用真实界面视觉、有目的的运镜、节奏化剪辑和声音设计讲清产品价值。

## 输入

只补充询问当前缺失的信息：

- 产品 URL、截图、录屏或前端素材。
- 品牌素材，以及必须保持准确的产品文字。
- 目标时长和画幅比例。
- 会影响剪辑的目标受众、发布信息与交付场景。
- 用户可选提供的 Ink Press 参考、镜头卡或动效示例。

不得声称本 Skill 内置 Ink Press 模板、镜头卡库、Remotion 工程或音频包。用户点名这些参考但没有提供素材时，应请用户补充参考，或确认其想复现的可见效果。

## 工作流

1. 检查用户提供的 URL 和媒体素材。保留产品真实的布局、字体、颜色、文案与交互逻辑，不虚构未经支持的功能或界面状态。
2. 确认时长与画幅。只有当平台或导出要求会实质影响构图、节奏或交付时，才补充询问。
3. 判断任务是完整宣传片还是单个动效镜头。用户提供的模板、Ink Press 示例或镜头卡只作为参考约束，不视为本 Skill 自带资产。
4. 给出可审阅方案，包括叙事结构、镜头顺序、运镜、界面重点、转场逻辑、屏幕文字、节奏、音乐或声音设计，以及所需源素材。
5. 在高成本生成或最终合成前停止并等待用户确认，明确指出缺失的截图、录屏、文案、Logo 或风格参考。
6. 用户确认后默认按总控冻结请求并执行 Seedance 2.5 生成视频镜头。如果用户明确指定其他模型，先检查该模型是否支持所需参考输入、时长、分辨率、画幅和音频需求，再遵循用户选择。
7. 用户指定的模型失败时，只允许在修正可能的参数、提示词或参考素材问题后在原范围、剩余上限与实际失败状态明确后才考虑一次有界重试；仍失败则记录原因并停止该任务；不自动切换模型或增加调用上限。
8. 只生成或选取已确认的声音素材，完成镜头剪辑，并检查视觉连续性、文字准确性、节奏卡点、音频平衡以及干净的首尾帧。
9. 保存最终交付文件，并说明输出格式、时长、画幅、参考素材，以及生成过程中发生的替换。

## 执行规则

- 表现真实产品界面时优先使用真实截图或录屏。
- 只有在有助于讲清产品时，才使用 2.5D 运镜、景深分层、裁切、推拉、平移、透视变化或视差。
- 产品与品牌可读文字必须准确，不得推断用户未确认的卖点、价格、指标或功能。
- 运镜与声音应匹配产品气质，避免装饰性动效干扰界面信息。
- 保留用户参考的动效意图，但要适配目标产品，不复制无关品牌内容。

## 边界

本 Skill 适合产品宣传片、发布短片、功能演示和 Web / 桌面产品叙事，不用于无关的通用剪辑、口播清理或非产品动效艺术。
