# 当前制作工具合同
本能力使用项目已接入的工具，不读取第三方聚合平台 Key，也不直接向其他供应商提交任务。

- 图片：Codex 内置 image2 生成库外候选，用户验收后入库；仅不可用、失败或用户明确要求时用项目图片模型。
- 视频：Seedance 2.5，按[总控执行规则](../../ai-drama-producer/references/execution-contract.md)冻结范围并执行。
- 旁白：有豆包语音 Key 时可用标准音色 TTS，ASR 用于实际对白核验；无 Key 时用 Seedance 原生声音并听音，不虚构独立音频结果。
- 音乐：独立音乐生成未接入。使用已授权音轨，或在视频原生声音中表达配乐方向，不承诺导出独立原创配乐。
- 合成：本地 FFmpeg。固定原对白时使用真实录音/TTS 文件作主时钟，先核实时长再切镜，不擅自变速。
- 预算与重试：由冻结请求中的上限控制；未知超时先查原任务，不无限重试、不静默换模型。
- 交付：真实播放、听音及字幕核验通过后记录质量结论与文件哈希。

素材类型、角色、参数和模式见[Seedance 专业指南](../../ai-drama-producer/references/seedance-prompting.md)。不存在“所有模型共用一个 Key”的假设。
