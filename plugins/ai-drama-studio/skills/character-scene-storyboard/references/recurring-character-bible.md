# 跨集人物档案：先证据，后候选图，再拍摄

在具体拍摄剧本前从已接受的成片提取所有已出现、可能再次出现的人物；角色表与章节记录交叉核对，未确定姓名的人物使用临时ID，禁止猜脸配名。

每人一个稳定ID；记录别名、首次/最近出现、已接受版本、成片时间码/帧号、源文件SHA-256，以及正面、左右三分之二侧面、侧面、全身能看到的证据。未出现的背面与身体细节标为推定，不能写成成片事实。

## 三层信息

1. 身份不变量：脸型、眉眼关系、鼻唇、发际线、年龄观感、肤色、头身比例、肩宽/身材、与固定参照人的相对身高。不要从透视镜头硬测厘米。
2. 衣装版本：每集服装、鞋、饰品与随身物；跨日可换装，脸和身形继续使用同一身份锚点。
3. 场次状态：油污、汗、血迹/伤情、衣领破损、道具持有者与数量。只在相应连续场次保留，不永久写进人物脸卡。

## 候选素材

用当前Codex内置图像工具（用户称image2），绑定已审成片的图像，生成中性灯光的正面脸、三分之二侧脸、侧脸和同尺度全身三视图。分开生成可提高辨认度；拼板只负责展示。生成面孔必须与证据比较，不以新图更漂亮为理由换脸。没有可用内置工具时说明事实，不偷偷换模型。

清单分为 extracted-evidence / generated-candidate / user-accepted / superseded，只有验收的精确版本可入生产参考。先把候选展示给用户，不先编完整拍摄计划来掩盖身份未定。

## 资产优先级与清理

用户最近认可的成片形象 > 较早认可的成片形象 > 前期设定图 > 未用过的配角/龙套库。后者可用于灵感，不能照搬为新身份。物品素材经检查可复用；场景按该场空间与剧情临时设计，不把旧场景图写成永久身份依据。

清理前必须保住成片、人物证据、母版清单、独立音轨/字幕、真实调用回执、可复用物品与必要权属信息。未被keep列表列出不等于垃圾；注册资产还要查最新计划/引用/运行任务。清理日志记录绝对路径、哈希、大小、理由及删除或隔离动作。历史失败参考从默认检索入口退役，保留简短问题说明即可，不能作为新镜头的默认参考。


## 同一个角色的声音锚点

从实际母版选独立发声片段，列说话人证据、语言、时间区间、原文件哈希及BGM/重叠对白污染。音区、共鸣、颗粒/鼻音、年龄感、语速与口音分别写，未试听不填结论。每人保留数句不同情绪，避免用一声喊叫代替声线。

预置音色匹配是候选筛选，不是声音克隆；用实际可用ID生成同一测试句并盲听。新旧音色交接要与前集对白直接对照，用户接受后锁定speaker和版本。语言与音色分开检查，普通话相似不能证明粤语正确。先定对白时间再排说话表演，逐句检查口型，禁止把静音画面＋随意配音宣称声画同步。
