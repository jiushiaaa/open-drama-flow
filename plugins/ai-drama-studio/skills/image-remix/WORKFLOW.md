# 图片灵感重混：完整制作工作流

> 本工作流由 OpenDramaFlow 总控调度，默认按 Seedance 2.5 当前适配器执行。

## 运行时合同

- 总控优先：必须完整阅读[总控执行规则](../ai-drama-producer/references/execution-contract.md)。默认 automatic，在用户目标与冻结上限内自动规划、自检和执行；专业阶段的方案/提示词确认不另设人工关卡，除非用户要求或当前为 manual。只要求提示词时不得启动生成。
- 图片：必须先阅读[图片生成与用户验收入库合同](../ai-drama-producer/references/image-asset-contract.md)。默认 Codex 内置图片工具（image2）生成库外候选，展示并经用户验收后才入库／完成任务；仅内置不可用、失败或用户明确要求时使用项目图片模型。自动执行不等于图片验收，也不等于批准生产记忆。
- 视频：Seedance 2.5 使用 `drama_request_paid_batch` 冻结请求，再用 `drama_authorize_and_start_paid_batch` 按当前策略启动；`drama_resume_paid_batch` 只恢复原有 waiting 任务。automatic 不弹产品审批框，manual 才要求可信确认，宿主权限独立。
- 提示词：必须阅读[Seedance 专业指南](../ai-drama-producer/references/seedance-prompting.md)，用当前能力与 ShotSpec 编译请求。参数由当前适配器校验，不继承其他供应商字段或强制节点流程。
- 声音：ASR 与标准音色 TTS 已接入，先查 `drama_get_capabilities`；没有语音 Key 时使用 Seedance 原生声音并实际听音检查。声音克隆、独立音乐生成、3D 编辑器与剪辑软件工程写入尚未接入，不伪造结果。
- 项目与资产：用 `drama_get_state` 读取事实、`drama_update_plan` 保存实际方案；稳定 assetId 与版本不随文件夹路径变化，本地路径不能直接充当供应商 URL。
- 完成：FFmpeg 用于确定性剪辑；生成/下载/探针成功不是交付。按总控检查实际画面、运动、对白、音轨与字幕，记录质量审核后才完成交付。

# 图片重混

从参考图中提炼视觉特征并创作内容全新的图片，不复制原主体，也不把不确定的模型溯源当成工具路由依据。

## 核心原则

- **保留感觉，替换内容**：保留已选择的视觉关系，重新设计主体和场景。
- **先分析再生成**：先识别参考图真正重要的特征，再写新提示词。
- **按能力选择生产路线**：根据风格、文字、参考和保真需求选择当前可用模型，不根据“原图可能由哪个模型生成”来指定工具。
- **透明使用参考图**：纯文字重建可以降低复制风险；直接使用参考图前必须确认授权和用户选择。

## 阶段 0：收集输入

收集：

- 一张或多张参考图；
- 用户希望出现的新主体或内容；
- 希望相似的部分：构图、色板、光影、质感、媒介、氛围或其组合；
- 最终交付画幅和变体数量；
- 参考图是否可以直接参与生成。

多张参考图要分别分析，并在生成前说明组合关系，例如“A 图构图 + B 图色板 + C 图光影”。

## 阶段 1：拆解参考图

从十个维度分析每张图：

1. 构图；
2. 美术风格；
3. 色彩关系；
4. 光影；
5. 氛围；
6. 质感；
7. 主体处理；
8. 叙事线索；
9. 后期特征；
10. 媒介或视觉流派。

把结果归纳为三个用户可理解的轴：

| 轴 | 组成 | 回答的问题 |
|---|---|---|
| **形** | 构图 + 主体处理 | 画了什么，如何排列？ |
| **韵** | 风格 + 色彩 + 质感 + 后期 + 媒介 | 由什么材质和调性定义？ |
| **意** | 氛围 + 光影 + 叙事 | 产生什么感受？ |

识别一到两个最突出的“灵魂维度”，并用画面中的可见证据支撑结论。分析深度参考 `references/analysis-example.md`。

模型或来源判断是可选且不确定的。需要时只把 `references/model-fingerprints.md` 当作视觉线索，说明置信度和备选判断，不能仅凭猜测选择模型或供应方。

## 阶段 2：确认重混方向

展示：

- 一句话灵魂总结；
- 形、韵、意的主要发现；
- 哪些元素保留；
- 哪些内容替换；
- 版权、身份或近似模仿风险。

确认一种路线：

- **文字重建**：只根据分析重建视觉特征，不直接提供参考图。用户想要灵感而非高相似时优先推荐。
- **参考引导**：需要更高结构或风格保真时，使用已获授权的参考图进行视觉引导。

用户没有新内容方向时，根据灵魂维度推荐三个替换概念。可使用“换主体”“保留美学”“保留构图”“保留氛围”等快捷方向。

## 阶段 3：构建提示词并生成

提示词应完整包含：

1. 新主体和新场景；
2. 已选择的“形”关系；
3. 已选择的“韵”特征；
4. 已选择的“意”和光影；
5. 已确认媒介和交付画幅；
6. 防止复制原主体、意外文字、水印、宫格和风格漂移的负向约束。

根据已确认生产需求选择模型。模型差异会影响参考保真、文字、写实度、插画风格或成本时，说明差异；用户指定的模型满足要求时优先采用。

用户需要探索时生成四个独立变体，因为这个数量足以比较构图和色彩，又不会让审阅负担过重。每个结果保持为独立图片，不做拼贴。用户只要一张最终图时，就生成一个聚焦结果。

## 阶段 4：审阅和迭代

展示结果后确认：

- 选择某张完成；
- 微调一个维度；
- 合并不同变体的优点；
- 更换新内容方向；
- 更换模型或生产路线。

尽量只调整受反馈影响的轴：

| 反馈 | 调整方式 |
|---|---|
| “色彩再冷一点” | 调整色板和色温描述 |
| “构图换成特写” | 调整景别、主体尺度和纵深关系 |
| “风格差太多” | 加强已确认媒介、质感和后期描述 |
| “这张构图 + 那张色彩” | 合并指定优点形成新方向 |

只有用户想保留的灵魂维度发生变化，或第一次分析不完整时，才重新分析源图。

## 阶段 5：交付

交付：

- 最终选定图片；
- 变体数量和迭代轮次；
- 灵魂总结及保留维度；
- 成功的可复用提示词或方向摘要；
- 本次采用文字重建还是参考引导；
- 剩余权利、身份或保真注意事项。

用户希望保存风格时，按 `references/analysis-example.md` 的结构记录精简风格卡，不写工具名或供应方请求字段。

## 失败恢复

- 参考图无法分析：请求更清楚的导出文件或替代图片；
- 来源判断不确定：省略来源，根据可见美学证据继续；
- 结果过度复制原内容：回到文字重建，替换更多主体细节；
- 风格特征太弱：只加强主要的形、韵或意线索；
- 参考引导不可用：说明保真变化，让用户选择文字重建或其他兼容模型；
- 变体太相似：在保留灵魂维度的前提下主动变化构图或色板。

## 边界

本 Skill 用于创作受参考图启发的新图片，不修改原图、不放大或转换文件、不精确复制受保护内容、不声称能确定识别源模型，也不生成视频。
