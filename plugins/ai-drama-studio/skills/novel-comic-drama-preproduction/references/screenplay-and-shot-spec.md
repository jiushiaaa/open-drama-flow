# 文学剧本与镜头规范

## 分集文学剧本

每集至少包含：

- 集号、标题、目标时长和来源章节；
- 开场钩子、核心冲突、高潮、结尾钩子；
- 场次编号、内外景、地点、时间、出场人物；
- 可见动作、表演、对白、旁白、环境反应和转场目的；
- 原文事实、原文台词与改编补充的区分；
- 本集新增、复用和变化的资产；
- 连续性状态：服装、伤势、持有物、位置、时间与人物认知。

完整不等于逐字搬运叙述。文学叙述必须转成可拍摄的动作、表演、声音或必要旁白，但不能删掉影响因果的内容。

## 导演分镜总览

总览用于审阅叙事与镜头节奏，应按场次列出：镜头段落、叙事目的、人物调度、视觉重点、声音策略、连续性风险和预计时长。它不是逐镜 Prompt 的缩写，也不能代替完整文学剧本。

## 逐镜生产合同

每个镜头至少包含：

- 稳定镜头 ID、所属集与场次；
- 时长、画幅、景别、机位、镜头方向和运镜；
- 起始状态、主体动作、结束状态和可见情绪；
- 台词／旁白原文、说话人、声音模式、环境声、音效和字幕；
- 静态画面描述与动态视频描述；
- 已批准参考素材的身份、版本、职责和连续关系；
- 生成模式、前后镜衔接、避让项和验收标准。

## Prompt 原则

- 静态描述回答“这一帧长什么样”，动态描述回答“在这段时间里发生什么”。
- 动作必须能在镜头时长内完成；复杂动作拆镜，不靠长句堆叠。
- 景别、机位和运镜服务叙事，不为专业术语而专业。
- 参考素材分别说明身份、服装、场景、构图、动作、声音或风格职责，避免互相冲突。
- 对白、字幕和原著原话逐字核对；不能只在 Prompt 中写“人物说话”。
- 当前能力不支持的输入、时长、分辨率或编辑精度不得写进生产合同。
