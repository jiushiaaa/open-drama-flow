# 阶段与关卡

阶段只能依据当前可核验证据推进，不能依据聊天承诺、文件夹名称或“看起来差不多”。

| 关卡 | 进入下一阶段前必须具备 | 阻断条件 |
|---|---|---|
| G0 授权与范围 | 权利声明、原文版本、哈希、目标卷／世界 | 来源不明、范围未定、缺章 |
| G1 原著证据 | 章节索引、人物与世界规则账本、原文差异登记 | 推断混入事实、关键证据不可定位 |
| G2 分集结构 | 全章覆盖、每集目标与时长估算、章节映射 | 机械等分导致内容无法容纳 |
| G3 文学剧本 | 完整分集剧本、来源标注、创作性补充边界 | 漏关键剧情、擅改原话或因果 |
| G4 资产计划 | 全卷资产清单、复用范围、视觉基准、验收标准 | 只按单镜补图、缺系列锚点 |
| G5 图片验收 | 用户接受的具体文件、哈希、版本和批准记录 | 只有生成授权、Agent 目检或候选图 |
| G6 导演包 | 导演总览、逐镜合同、Prompt、声音与字幕意图 | 镜头不可执行、引用未批准素材 |
| G7 全卷审计 | 来源覆盖、连续性、时长、素材与状态错误为零 | 未解决争议、缺失、重复或失效引用 |
| G8 正式入库 | 仅明确、已批准、可复用版本进入项目资产 | 草稿、候选、废案、旧状态残留 |
| G9 开拍前冻结 | 卷级清单、冻结版本、预算上限和验收标准 | 生产输入仍会变化、就绪报告失败 |
| G10 开拍决定 | 用户明确批准开始视频制作 | 沉默、同意方案、批准图片均不能替代 |

## 失效规则

- 原文或卷范围变化：G1 之后全部重新核验。
- 分集结构变化：受影响剧本、资产需求、分镜与 Prompt 失效。
- 剧本事实变化：受影响资产、分镜、声音与 Prompt 失效。
- 图片内容变化：新文件必须重新验收，并更新所有冻结引用。
- 仅文件夹移动：稳定资产身份和版本不变，不应让已批准内容失效。
- 仅验收标准变化：保留已生成文件，但必须按新标准重新审阅。
