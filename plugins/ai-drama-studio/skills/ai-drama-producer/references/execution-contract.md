# 总控执行规则

更新：2026-09-03。所有专业 Skill 的执行策略、工具调用及验收边界均服从本合同；专业正文只决定制作方法，不得覆盖总控规则。

## 默认自动，不是无限授权

- 用户要求制作时，在已授权目标、资产、版本、次数和费用范围内，默认按 `automatic` 连续推进理解、规划、提示词自检、生成、检查、修改与交付。不要求用户逐阶段点击确认，也不要求手动添加画布节点。
- 用户只要求分析、方案或提示词时，交付相应内容，不自动生成或入库。范围不清、授权素材缺失、需要扩大费用/调用上限、改变交付目标时才问一个必要问题。
- 旧正文中的“先确认方案”“暂停确认提示词”“确认后调用”在 automatic 下表示 Agent 对照用户目标与当前状态自检并记录，不代表等待人工操作，更不得记录成“用户已批准”。用户明确要求逐次/逐阶段审批或当前策略为 `manual` 时才走对应人工确认。
- 不因 manual 被取消、不可用或失败而切换 automatic。Codex 的宿主权限是独立边界，插件不得绕过。

## 视频执行链

1. 读取 `drama_get_state`、当前批准的上下文及 `drama_get_capabilities`，按总控保存实际方案，用 `drama_get_next_actions` 确定下一步。
2. `drama_request_paid_batch` 冻结方案、提示词、参考资产版本、模型参数、次数上限与 `requestDigest`；它只建请求，不调用模型。
3. `drama_authorize_and_start_paid_batch` 才开始任务。automatic 记录 `automatic-policy`；manual 由受信任的 MCP 表单批准。不得伪造人类确认。
4. `drama_resume_paid_batch` 只续跑原有 waiting 任务，不是首次启动接口，也不替代授权。超时先查原任务；失败不会自动授予新增次数，禁止无界重试或静默切模型。
5. 修改输入必须重新冻结并按当前策略授权；超出用户范围必须先询问，不得新建请求绕过已耗尽的调用上限。

## 始终保留的人工验收

- **生成图片**：先读[图片合同](image-asset-contract.md)。默认 Codex 内置图片工具（image2），候选留在项目素材库之外，展示给用户，只有用户验收的确切文件/哈希才入库或完成图片任务。Agent 目检、自动执行、设计认可都不等于成图验收。内置工具不可用、失败或用户明确指定才启用项目图片模型；候选规则不变。
- **生产记忆**：候选提炼不代表事实成立。只有 `drama_review_memory` 的可信批准才能激活该版本；不得把候选自行提升为已批准的角色或世界观事实。
- **其他审核**：Agent 可按总控进行实际媒体质量检查并记录证据，但不能把未播放、未听音、未读出的内容标记通过，也不能把内部检查标记成人工验收。

## 当前声音与工具边界

- 视频主路线为当前适配器支持的 Seedance。需要原生声音时显式使用 `audioMode: provider-native`；静音用 `none`。不能只在提示词里写“有声音”而忽略开关。
- 豆包语音 **ASR 与标准音色 TTS 已接入**，是否可用取决于当前配置、权限和实际响应。可用时用 `drama_request_speech_job` 冻结单次范围 → `drama_authorize_speech_job` 按 automatic/manual 执行 → `drama_get_speech_job` 查询。没有语音 Key 时仍可用 Seedance 原生声音，不阻断视频制作。
- ASR 仅是带来源的识别证据，需要对照原音；不是自动字幕验收或生产记忆。TTS 产物要试听，再显式绑定所需镜头，不静默替换已确认音轨。
- 独立音乐生成、声音克隆、3D 编辑器、剪辑软件工程写入仍未接入。现成授权音频或 Seedance 原生声音可以使用，但不能冒充这些独立能力。常规剪辑、字幕、混音使用 FFmpeg。
- 其他模型资料 的示例、私有字段、工具菜单与供应商名只作迁移/比较材料，不是可调用接口。生产提示词先读[Seedance 专业指南](seedance-prompting.md)，并以当前适配器合同校验，不以教程或模型品牌推断能力。

## 完成证据

遵循[工作流合同](workflow-contract.md)与[供应商合同](provider-contract.md)：保留原任务 ID、版本与输入哈希；生成成功不等于交付。成片需播放检查运动、身份、声音、字幕与连续性，记录质量证据，最后用 `drama_finalize_delivery` 生成与已审文件匹配的交付清单。无法检查的项目保持待核验。
