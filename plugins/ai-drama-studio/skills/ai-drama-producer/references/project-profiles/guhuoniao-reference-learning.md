## 一条参考如何进入制作

1. **登记输入**：文件/来源、哈希或版本、视频时码、原著章节/行号；明确检查范围。抽帧不能冒充全片播放，字幕不能冒充实际听音，标题不能证明供应商或参数。
2. **拆解证据**：可见事实、原著事实、创作者自述、我们的推断分别记录。记录一项长处时同时记录适用条件与不该照搬的部分。不把画面里看不出的模型、提示词、首尾帧或续写流程当作已证实。
3. **转为本项目方法**：写清“针对什么问题 → 如何改变镜头/表演 → 如何验收”，而非只增加“电影级、流畅、双城之战”等形容词。一次实验围绕一个主要问题，其余已认可要素保持稳定；不为机械控制变量限制必要修复。
4. **按需验证**：仅重做当前镜头必需素材，Agent按用户已授委托检查素材，再交一段视频由用户审。不要先翻新全库或一次生完整集；外部视频不默认上传供应商充当动作输入。
5. **分级沉淀**：用户要求=当前约束；参考观察=证据；迁移方法=待样片验证；本项目成功经验=有确切视频版本/哈希、时码与用户认可。失败记录保留原因，不能把重试成功猜成通用参数。

## 连续动画而非会动的图片

- **以事件为单位写表演**：起始状态 → 动机/刺激 → 主动作 → 接触/转移 → 缓冲/反应 → 下一镜交接状态。选择场景实际需要的环节，不把每次微表情都硬凑成六拍。
- **文戏也要状态改变**：凝视、迟疑、收回注意、停下手中动作都可构成表演；不是所有镜头都必须走动。呼吸、眨眼、发丝和镜头推拉只能辅助，不能单独冒充已发生的戏剧事件。
- **动作层次由因果驱动**：例如听到声音，先改变注意，再有眼神、头肩转向；时差按情绪设计，不让所有肢体同相机械运动，也不写死毫秒延迟。
- **物理接触连续**：手接触物体时位置、抓握和承重成立；落地/靠近/离开应有重心变化。衣摆与发束跟随主体动作，不单独风吹循环。电视内演员同样需要表演，不是屏幕贴一张脸轻晃。
- **切镜交接**：每个切点记录动作已到哪一步、屏幕运动方向、眼线、人物位置、手里物件、门/座椅状态、声音是否延续。切后承接动作，不再演一遍起始姿势；不用叠化掩盖错位、人物消失或时间倒退。
- **停顿允许、僵滞不允许**：停顿要有等待、压抑或观察的目的；并非剪得越碎、镜头越多、动作越大就越像动画。

## 小说到镜头

将文本先分为：情节事实、人物认知/情绪、环境叙事信息、可自由设计的镜头调度。只有最后一类可以在现有授权内灵活安排；前几类不能因参考片好看而移植别人的情节、台词或人物关系。

环境由角色的注意线串联；阅读招牌、海报和唱片有明确观察对象及停留机会。相关文字必须清晰，其余背景可做层次化简化；不把“背景能虚就虚”理解成把原著点名信息一起糊掉。改写时间顺序或增加重大事件先确认；对照有限章节不能断言某场戏是全书新增或删除。

## 历史SC002迁移记录（2026-09-06，不再是当前待办）

以下保留当时的设计与失败背景，供理解动画表演方法；第一章现已获用户认可，不据此重新生成店内画面。新的工作范围以当前用户指令为准。

- 电视：设计有呼吸准备、握麦/贴近、发力及释放的演唱动作，让肩颈、下颌、目光和身体共同表达声嘶力竭；不靠噪点/扫描线或夸张循环摇头掩盖假表演。嘴形和动作对原曲实际声音检查，不声称精确同步已实现。必要时单做演唱画面再合成电视，属于实现选项而非已证实能力或已完成结果。
- 店内：雷晶观察 → 环境信息进入视野 → 画外声音打断 → 雷晶注意转移 → 看到李阎。主观视角的转头/停步应有动机，不用静物轮播代替观察。
- 李阎：声源、目光及人物出场构成同一事件；若添加整理录像带等小动作，标成调度提案并核对身份、情境，不伪称原著动作，不新增实质剧情。

## 验收与归档

先正常速度观看完整新段并听音，再针对起步、接触、释放、每个切点及异常处逐帧/密集检查；逐帧与正常播放互补。逐项写具体时码证据：
表演状态是否推进；有无闪回/跳姿/无因漂移；人物/门位/道具是否一致；声音、口型和双语字幕是否同步；四条三渲二规则是否保留。
未实际观看/听音的维度标为待验，不因抽帧顺眼、清单齐全或编码成功而通过。复核原母版哈希未变。
