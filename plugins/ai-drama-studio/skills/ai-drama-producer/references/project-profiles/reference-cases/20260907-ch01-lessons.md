## 2. 原著与导演表达的边界

原著剧情走向、因果、人物身份及已认可台词是硬约束；镜头、时长、机位和非关键调度可以调整。不得为了凑45秒、30秒或一个模型调用而压缩成不自然动作，也不擅自改写台词。

## 4. 擦鼻子返修：必须记住的最终要求

用户最后不是要“脸先流血，再把血擦干净”，而是：

**说完话，脸正常干净 → 面纸擦一下鼻子 → 看纸上的血 → 脸仍正常干净，人物外观不变。**

- 脸上不需要先出现血；第二秒突然冒血也是失败。不要自行增加病态变白、残留红斑、湿痕或第二次流血。
- “干净”与“变白”是两件事；用原肤色、面部形体与阴影作保留项，不把清除污迹解释成美白磨皮。
- 多次皮肤贴片、近邻帧覆盖、局部色彩补偿出现闪烁/肤色断层后，停止沿该失败路径叠补丁。静态素材局部编辑有价值，但不能据此断言动态视频逐帧覆盖也可靠。
- 完整重生只覆盖必要动作单元，保留其他已认可镜头。长镜头出现状态过载时简化目标，而不是越失败越堆动作和负面词。

## 5. 人物、场景、表演的最小准备

每场只准备本场需要的资料；不要为学习教程预先翻新全库。人物与场景教程详见[一致性案例](20260907-character-scene-consistency.md)。

1. **原著与授权范围**：需要拍到哪里、原台词及剧情动作、哪些调度可变。默认一段供审；只有本次明确授权才扩大，不能沿用过去“睡觉时做完整文戏”的临时范围。
2. **身份与状态**：认可身份参考及版本；服装参考用途；起态/触发/末态；本镜不允许变化的脸型、发色、肤色、衣服。血在纸上和血在脸上必须分开表达。
3. **空间与人数**：门、窗、沙发、茶几、电视、书架的相对位置；视轴与主光；在场者/入画者/画外者。未知空间先在需要时补足并核对，不把生成俯视图当测量事实。
4. **动作交接**：前镜实际末态，本镜接触物与道具手，主要动作和收势，后镜所需初态。选首尾帧、末帧链或视频续写前核对真实接口支持及输入职责；三种方法并非同一个保证。
5. **声音与字幕**：已有认可声音优先；原曲可后期作为电视声源，不能为了音频审核受限反复让模型重唱或绕过限制。用户提供文件与用户的权利声明分开记录，不替其出具法律保证。后期混音应服务屏幕声源空间，不能只把音乐铺满画面。

## 6. 返修与审片的选择标准

- **错误插帧/多余起手**：先查真实切点，精确重剪；不要把整个镜头默认重生。
- **错误身份、道具遮挡、动作因果或动态贴片失稳**：用合适参考重生必要完整动作单元。是否重生由当前缺陷决定，不固定“后期永远优先”或“全部重生”。
- **参考首尾已不一致**：先解决参考冲突；不能把错误末帧传给下一镜。后续样片通过也要再检查合片入口和出口。
- **失败与恢复**：区分认证响应、网络/下载、供应商排队、参数/素材不兼容、内容审核、编码/时间线错误。缓存清理或重启只是线索，不直接判断API key失效；未知任务先查原ID，成功文件的后处理失败不等于需要再次付费。不得打印或把密钥写入项目文档。
- **重试**：用户不要求省调用，已授权范围内遇可恢复失败无需逐次确认；每次保留原因、改动和明确次数范围。相同失败反复出现应改变调度或输入策略，不能无界重复请求。
- **检查**：正常速度播放和听音；关键动作、面孔显露、源片内部切点及合片接点连续帧检查；抽帧、ASR、解码、哈希各只证明其对应事项。未执行的维度明确待验，不把用户认可补写成内部已检查。
- **保护**：另存新版本；记录来源/版本/哈希、替换帧区间、字幕与音频映射、实际检查结果及用户反馈。当前认可版本优先于同名旧图、废案或历史“最终候选”。
