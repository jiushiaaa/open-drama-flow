# 教育视频生产管道

遵守[教育主工作流](../WORKFLOW.md)与[总控执行规则](../../ai-drama-producer/references/execution-contract.md)。automatic 不要求用户逐阶段选择；必要事实缺口、用户指定审核、图片验收入库和生产记忆批准仍按总控处理。

## 计划分层

| 层 | 保存内容 | 消费方式 |
|---|---|---|
| 教学 Brief | 受众、目标、来源、完整旁白、统一风格、预算 | 创作规划与事实核查 |
| 逐镜教学记录 | 知识点、视觉证据、观察任务、台词、动作和转场 | 编译自然语言 videoPrompt |
| 实际 ShotSpec | 模式、时长、参数、显式声音、真实 mediaReferences | drama_update_plan 和冻结请求 |
| 后期与审核 | 全片时码、音画层、字幕、版本、问题和证据 | FFmpeg、审片与交付清单 |

这些是规划层，不是新供应商 API。读取实际 schema 后传参；不用不存在的 text-node、replace、expectedContentHash 参数冒充计划编辑接口。文档和资产使用真实可用工具保存，写后重读；聊天旧稿不能覆盖用户刚修改的正文。

## 逐镜教学记录

每镜写明：
- 片段编号、全片位置、局部 0 秒起的时间轴、计划与提交 duration。
- 画面内容、景别、机位、运镜、主体/角色/道具、入镜和出镜状态。
- 知识点、教学功能、视觉证据、学生观察任务和事实复核点。
- 逐字台词、说话人、语气、读音、声音起止与环境声。
- 屏幕文字、公式、数字、单位、字号层级、位置、安全区及出现/退出时机。
- 参考 assetId、版本、职责、实际输入顺序；不存在的素材标缺失。
- 每次切换的前镜动作、切点、转场方式/持续时间、承接的知识关系和后镜构图。
- 明确要避免的错误，但不堆积相互矛盾的负面描述。

技能演示额外记录正确动作对照和安全点；概念解释补充视觉比喻。镜头内不必强制多次切换，数量由知识推进决定。

## 旁白容量与真实时序

纯旁白先估声音再配画面。以约 3 字/秒为中文教学起点，按年龄与难度调整；数字、英文和公式按实际读音折算。逗号、句末、段落、换气均计停顿；再加必要的阅读或观察缓冲。此为教学规划启发，不是 Seedance 模型硬上限。

duration 必须合法且容纳台词和动作。超出上限沿语义拆段；短于下限优先合并相关语义。不要统一塞成固定几秒，更不能用快速朗读、截断或无意义尾部静音掩盖不匹配。

生成后以真实音轨复测：每段 VO 绑定相应镜头或明确区间，关键词与对应证据对齐。声音长于画面时回到该段调整内容、动作节奏或合法延长；不能仅用 -shortest 截断句尾或比较全片总时长就判通过。

## 视觉路线与声音策略

先查能力，再选 text-to-video、image-to-video、first-last-frame、multimodal-reference、video-extend 或 video-edit。具体角色、约束和窗口见[Seedance 专业指南](../../ai-drama-producer/references/seedance-prompting.md)。

新关键帧默认使用 Codex 内置 image2；在库外展示候选，用户接受确切图片后才登记 assetId 并用于 Seedance。已批准人物、场景、版式母版直接复用，不按每个画面事件重复生成。

声音在执行前显式选定：
- provider-native：台词、环境声与音乐由视频模型共同生成并实际听音。
- source-asset/post：确有授权现成音轨或可用标准 TTS 时，按当前音轨合同绑定和后期对齐；不静默替换原生音轨。
- none：需要无声时明确关闭，不能只删除提示词音频文字。

ASR 可核对术语、台词和时间，但不证明音色一致或演绎质量；TTS 只读准确正文，声音选择使用真实配置。无语音 Key 时不阻断原生声音路线。独立音乐、声音克隆与编辑器工程写入不在当前工具能力内。

## 文字、公式与信息节奏

术语首次出现给出定义；公式、题目条件与推导分步显示。先锁准确文案，再定字体、颜色、位置和动效。每个新概念有“出现—解释—回收”，避免多种新信息同时抢注意力。

内容生成与确定性排版分工：复杂公式、准确数字、答案、字幕可用实际渲染/FFmpeg 叠加，不承诺模型逐字无误。时间线、地图、比较卡片、题目、反馈与系列编号都服务于知识关系。

全片包含开头问题/异常现象、逐镜观察任务和结尾理解检查；通过不同尺度、动作、构图增加证据，而不是更换滤镜堆丰富度。

## 修改、预算与验收

修改前读最新方案和原文，只更新受影响镜头、字幕、VO 与后期位置；保留旧资产版本。重新冻结变更的模型请求，不能复用不匹配的旧授权摘要。

预检统计总时长、片段数、必要图片数、可选 ASR/TTS 和剩余调用额度。不能通过新建批次绕过耗尽的上限。图片验收与生产记忆批准不随自动策略消失。

实际播放并检查事实、教学、运动、身份、声音、字幕、排版与连续性。保留失败原因和待核验项，修复后复核；不能隐藏缺陷，也不能用节点 ID、下载成功或抽帧代替成片验收。输出真实媒体文件与版本清单，不伪造编辑软件工程。
