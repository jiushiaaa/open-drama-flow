# 教育内容工作室：完整制作工作流

> 本工作流由 OpenDramaFlow 总控调度，默认按 Seedance 2.5 当前适配器执行。

## 运行时合同

- 总控优先：必须完整阅读[总控执行规则](../ai-drama-producer/references/execution-contract.md)。默认 automatic，在用户目标与冻结上限内自动规划、自检和执行；专业阶段的方案/提示词确认不另设人工关卡，除非用户要求或当前为 manual。只要求提示词时不得启动生成。
- 图片：必须先阅读[图片生成与用户验收入库合同](../ai-drama-producer/references/image-asset-contract.md)。默认 Codex 内置图片工具（image2）生成库外候选，展示并经用户验收后才入库／完成任务；仅内置不可用、失败或用户明确要求时使用项目图片模型。自动执行不等于图片验收，也不等于批准生产记忆。
- 视频：Seedance 2.5 使用 `drama_request_paid_batch` 冻结请求，再用 `drama_authorize_and_start_paid_batch` 按当前策略启动；`drama_resume_paid_batch` 只恢复原有 waiting 任务。automatic 不弹产品审批框，manual 才要求可信确认，宿主权限独立。
- 提示词：必须阅读[Seedance 专业指南](../ai-drama-producer/references/seedance-prompting.md)，用当前能力与 ShotSpec 编译请求。参数由当前适配器校验，不继承其他供应商字段或强制节点流程。
- 声音：ASR 与标准音色 TTS 已接入，先查 `drama_get_capabilities`；没有语音 Key 时使用 Seedance 原生声音并实际听音检查。声音克隆、独立音乐生成、3D 编辑器与剪辑软件工程写入尚未接入，不伪造结果。
- 项目与资产：用 `drama_get_state` 读取事实、`drama_update_plan` 保存实际方案；稳定 assetId 与版本不随文件夹路径变化，本地路径不能直接充当供应商 URL。
- 完成：FFmpeg 用于确定性剪辑；生成/下载/探针成功不是交付。按总控检查实际画面、运动、对白、音轨与字幕，记录质量审核后才完成交付。

## 任务与执行策略

先识别学习问题，选择最小充分的交付物。用户只要讲解、教案、题组或脚本时，不启动视频生成。制作任务按总控 automatic 在已授权范围内连续推进；只问会改变目标、事实或授权范围的必要问题，不固定弹六组选项卡。manual 或用户要求审核时才暂停对应阶段。

| 目标 | 主交付 |
|---|---|
| 理解概念、学习技能 | 目标、先备知识、讲解、例题与理解检查 |
| 备课、授课 | 教案、课件结构、活动、时间分配和教师提示 |
| 练习、考试 | 题目、难度、答案、解析、评分标准与错因 |
| 科普、微课 | 受众化脚本、视觉证据、旁白、镜头表、字幕与成片 |
| 素材加工 | 转录、纠错、摘要、术语统一与知识点切片 |

视频任务读取[教育视频管道](references/education-video-pipeline.md)和[视觉制作](references/visual-production.md)；评量任务读取[评量设计](references/assessment.md)。

## 1. 教学 Brief 与学习路径

提取主题、受众年龄/水平、最多三个可观察学习目标、先备知识、语言、格式、已给素材及限制。保留用户明确的总时长与画幅；未指定时先按内容估时并说明合理默认值，不要求用户凭空选择秒数。

按“激活先备知识 → 核心概念 → 具体例子与反例 → 引导练习 → 独立练习 → 退出检查”组织。儿童/初学者用短句、单一变量和可视化；进阶者明确假设、边界、误区与迁移；职业培训聚焦真实决策和可执行产物。

每个知识点对应一个认知动作及至少一个可见证据。事实、公式、单位、引用和答案须可复核；未知项标注待核验。实验、医疗等高风险主题区分教学演示和现实操作建议。

## 2. 叙事与统一风格

先选讲法，再选美术，不把美术变化当成知识推进：

- 剧情叙事：具体情境中的问题与解决。
- 讲师讲解／角色问答：陈述、提问、质疑与回答。
- 板书推演／图解海报：逐步展开公式、结构与对比。
- 实验实操／案例观察：观察真实过程、证据与结果。
- 沉浸探索：用空间和尺度变化解释关系。
- 混合讲解：一个主形态贯穿，其他形式补充。

保存统一风格锚点：媒介、主体与背景、构图、线条/材质、色彩/光影、信息层级、镜头韵律及要避免的错误。继承已明确的选择；automatic 可自行选取并记录适合受众的方向。

每段旁白绑定其视觉功能：提出问题、观察现象、拆分结构、表现因果、对比、演示、揭示结果或回收。相邻镜头通过主体、空间、尺度、动作或构图推进信息，不为填时间添加无教学目的空镜。

## 3. 声音和时长先行

先标记纯旁白、出镜口播、角色对话或无人声演示。逐字记录台词、说话人、发音风险、语气、局部起止时间和观察任务。

中文教育旁白可从约 3 字/秒估算，低龄适当放慢；数字、公式、英文按实际读音计数。基础朗读时长加标点/呼吸停顿和必要的观察时间后，再匹配当前模型合法 duration。估算不是声音证据，实际音轨生成后必须复测。

超出用户总时长时精简重复信息；超出单次模型上限时沿语义拆段。不要加速硬塞、删除停顿或仅改 duration。无人声观察和实验动作允许有明确目的的安静区间，不强制套旁白语速规则。

- 原生方案：显式 audioMode: provider-native，将逐字台词、环境声和音画同步写入 videoPrompt。
- 独立 VO：语音能力可用且任务需要时，通过真实语音任务链生成标准音色 TTS，再试听并绑定；使用工具实际支持的 text 字段，不把音色说明或指令混进朗读正文。
- 没有语音 Key：可继续用 Seedance 原生声音；不得承诺独立声音克隆、独立音乐或不存在的音色样本工具。
- 已有授权音轨：按资产版本绑定。保留、替换或静音显式记录，不能叠出双重人声。

## 4. ShotSpec、参考与执行

先查 drama_get_capabilities，读取最新项目状态。Brief 和镜头说明可保存为真实文档；drama_update_plan 只写其 schema 定义的计划字段，不接受虚构的 text-node 编辑 API、nodeId 或 contentHash 返回约定。文档编辑使用实际文档工具/资产接口；写后重读核验。

逐镜至少记录：教学目的、视觉证据、局部时间轴、主体动作、景别/机位/运镜、入镜/出镜状态、转场、逐字台词、准确屏幕文字、音色/音效、assetId 与版本、videoInputMode、duration、videoParameters、audioMode。创意规划字段与 API 参数分开，不能原样把自定义规划对象交给供应商。

根据任务选择直接生成或先准备关键帧；已有合格参考直接复用。需要新图片时默认 Codex 内置 image2，库外展示，用户验收后入库再绑定下游。图片验收不能以 automatic 或 Agent 自检替代。

- 一般多参考：multimodal-reference + reference_image/reference_video/reference_audio。
- 开始帧：image-to-video + first_frame。
- 双约束：first-last-frame + first_frame/last_frame。
- 续写或局部修改：按总控指南使用 video-extend/video-edit，绑定真实源视频及窗口；不能伪装成首帧或像素级编辑。
- 文本中“参考图1/音频1”须与实际输入顺序一致，不把本地路径当可访问 URL。

保存计划后 request 冻结，再 authorize-and-start。既有 waiting 任务才 resume；超时先查询，不重复提交。调用次数、图片数、TTS/ASR 数与重试预算均计入授权范围。

## 5. 修改与交付

先重读当前文档与计划，按用户要求最小修改；重算受影响的声音容量、镜头边界、提示词、字幕和时间线。保留未受影响资产及已锁定版本。输入改变时创建新冻结请求，不改写旧审批快照，也不冒充用户批准。

后期使用现有 FFmpeg：逐镜对齐音画、必要裁切与混音、精确字幕/公式/数字叠加。未接入的剪辑软件工程不能宣称导出成功。严格公式、答案与品牌文本优先确定性排版，不把生成模型的文字精度当保证。

交付前：
1. 目标、活动与评量一一对应，难度匹配受众。
2. 事实、术语、公式、单位和答案可核对。
3. 播放检查动作、身份、转场、语音、音轨与字幕；ASR 仅提供辅助文字证据。
4. 每段关键词对应正确视觉证据，结尾有理解检查或迁移题。
5. 保留真实文件、任务 ID、资产版本、审片记录；无法核验项不得标为通过。
6. 通过总控交付接口生成最终清单，说明成片与可用源文件位置，不以画布节点存在代替完成证据。
