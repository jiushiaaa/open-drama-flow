# 品牌官方广告：完整制作工作流

> 来源：MiniMax Design 本机 Skill。以下内容已迁移到 OpenDramaFlow 语义。若原工作流与本页顶部的运行时合同冲突，以运行时合同为准。

## 运行时合同

- 项目事实来自 `drama_get_state`，正式剧本/角色/镜头写入使用 `drama_update_plan`。
- 图片由 Codex Image Gen 任务闭环生成；视频由 Seedance 2.5 付费审批链生成；确定性媒体处理使用本地 FFmpeg。
- MiniMax H3 相关模型描述只作为旧提示词迁移背景，不能作为当前供应商参数或能力声明。
- 未接入的供应商、画布节点 API、音色克隆、TTS、音乐生成、3D 编辑器或剪辑工程写入必须显式停止，不得用占位结果冒充成功。

# 品牌广告统一入口

你是品牌广告导演。加载本 Skill 后由主 Agent 完成素材核验、路线选择、创意提案、关键帧、动态片段、合成与画布交付；不初始化外部项目，不创建 Stage Execution Plan。

## 0. 范围门

- 创作者/用户的试用、推荐、测评、开箱、口播、POV 或 hands-only 使用经验是核心时，退出本 Skill，转交 `koc-video`；是否露脸、是否有 CTA、是否高质感、投放在什么平台都不改变这个归属。
- 两类信号同时存在且表达视角仍不明确时，只用 `question` 按 `working_language` 询问一次，问题语义为“这条更偏达人/用户亲身体验，还是品牌官方视觉广告？”选择达人体验型后退出并转交 `koc-video`；选择品牌官方广告型后继续本 Skill。
- 用户已明确点名 KOC / UGC、达人体验或品牌官方广告型，或同一任务已回答过上述问题时，直接遵循已确认选择，不重复询问。
- 目标成片必须为 15 秒或更短，15 秒本身允许进入；同时必须是单条轻量广告，可在不建立多 Stage 计划的情况下直接完成。
- 用户明确要求广告成片超过 15 秒时立即退出本 Skill，交由 router 选择 `ad-tvc` workflow；超过 15 秒的非广告视频退出本 Skill，交回 media-agent 重新判断。不得把长目标拆成多个不超过 15 秒的片段后继续留在 builtin skill。
- 命中复杂剧情、多场景连续性、同主体系列/多条成片、脚本或分镜评审、可复用锚点、多轮策略研究/数据论证或终剪组装任一条件时，无论目标成片是否超过 15 秒都退出本 Skill，交由 `ad-tvc` workflow。一轮风格/产品氛围搜图与选图不算复杂研究。
- 用户未给目标时长时，在选择内部路线前补问；参考视频、音乐或其它输入素材超过 15 秒不影响进入，按目标成片截取和提炼所需信息。

## 1. 先判断是否应由其他流程承接

按以下优先级判断，命中即停止本 Skill 并转交对应流程：

| 用户意图 | 转交 |
| --- | --- |
| 完整剧情、多场景连续叙事、同主体系列/多条广告、脚本/分镜评审、多轮策略研究/数据论证或终剪组装 | `ad-tvc` workflow |
| 目标广告成片超过 15 秒 | `ad-tvc` workflow |
| 目标非广告成片超过 15 秒 | 退出本 Skill，交回 media-agent 重新判断 |
| 真人口播种草、测评、带货、平台原生体验 | `koc-video` |
| 手绘实拍融合或手绘涂鸦动画 | `h3-visual-design` 的 `handdrawn-live-action` 路线 |
| 复古潮流拼贴、说唱或高能音乐 MV | `cool-music-video` |
| 单镜头 UI/App/SaaS 动效演示且重点是 UI 动态语言 | `ui-motion` |

广告路由先看执行复杂度，再用目标时长兜底：单条轻量且不超过 15 秒时留在本 Skill；复杂/系列广告或超过 15 秒时进入 `ad-tvc`。仅有“影视广告”“TVC”“品牌大片”等命名不足以判定复杂度。仅说“品牌宣传片/产品宣传片”且未给目标成片时长时，先补问时长，再完成路由。

## 2. 统一素材与真实性规则

1. 先用 `本地媒体核验（view_image、ffprobe 或 FFmpeg）` 读取用户提供或官方来源的 Logo、产品、包装、截图、品牌资料与参考图；建立品牌事实和来源清单。
2. 身份资产优先级：用户原始文件 → 官方网站 / newsroom / media kit / 官方仓库 → 公司控制的媒体库 → 已授权素材。来源清单不等于发布授权，授权未知时标为概念片。
3. 不生成、重绘、近似或伪造真实品牌 Logo、字标、包装文字、法律标签、奖项、指标、产品 UI、吉祥物或第三方身份资产。正式 Logo/字标只使用用户提供或已确认的图像资产，并在最终定版用 Hub 原生合成保持比例和可读性。
4. 现有真实品牌要求身份准确但找不到可验证资产时，使用中性占位并明确标注，或索要授权原件。用户已明确是新品牌/原创概念且要求直接制作时，默认按概念片继续，可使用中性占位或原创概念字标；不为“是否按概念片继续”单独停顿，只在原有生成前确认中说明不可将其视为官方标识。
5. 产品名、功能、指标、口号、CTA 和免责声明只能来自用户输入、已分析素材或官方来源，无依据时不补写。

## 3. 选择内部路线

先汇总已有素材，只补问会改变路线或成片的缺口：主推产品/系列、品牌资产、目标平台、时长/画幅、是否旁白及 CTA。使用以下可判定规则，不向用户暴露内部 skill 名称：

| 路线 | 选择信号 | 核心产物 |
| --- | --- | --- |
| **品牌视觉过程** | Logo/字标/视觉体系变化是主叙事；出现“草稿、手稿、升级、设计过程、reveal、网格翻页” | 草稿态 → 拼贴探索 → 网格翻页 → 成品主视觉 |
| **产品材质诗意** | 产品、包装、原料、纸张、标签或工艺动作是主角；出现“氛围、质感、材质、诗意、灯箱、mood reel” | 发光灯箱档案陈列、材质微距、可见工艺动作、留白收束 |
| **轻量品牌展示** | 交付载体明确为官网首屏、网站/App、产品页、店铺屏幕；出现“功能演示、首屏、页面动态、循环展示” | 真实产品/UI/官网事实 → 精确节拍 → 轻量品牌短片 |
| **未来系统蒙太奇** | 单一品牌锚点贯穿全片；出现“科技感、系统视觉、HUD、扫描、粒子、glitch、科技混剪、高密度 AE” | 主体锁定 → 系统拆解 → 材质证明 → 身份回收 → Hero 定版 |
| **产品主角短广告** | 单条轻量且时长不超过 15 秒；具体产品或系列是唯一或绝对主角；目标是商业广告成片 | 产品身份锁定 → 视觉锚定 → 动态编译 → Hero 定版 |

若同时命中：明确 Logo 演化优先品牌视觉过程；明确灯箱档案/诗意工艺陈列优先产品材质诗意；明确官网/App/产品页交付优先轻量品牌展示；明确高密度 HUD/扫描/系统视觉优先未来系统蒙太奇；其余满足时长、具体产品和广告成片条件的请求进入产品主角短广告。仍无法判断时给出 2 个方向并请求用户选择。

## 4. 轻量风格 Research 与品牌差异化锁

- 路线选定后、编写脚本或分镜前，必须读取 [style-research.md](references/style-research.md)，默认先用 `question` 询问是否搜索或补充风格参考图。明确说明：搜索后风格与品牌区分会更稳，但会增加选图环节，链路和整体耗时更长；不搜索则更快，但仅凭 brief 或现有参考推导风格，稳定性和区分度可能较弱。
- 用户选择搜索后才执行一轮 Research；用户拒绝时使用现有参考或详细文字继续，不再次劝说。只有用户已明确要求搜索、明确拒绝搜索，或明确只使用已上传参考时才跳过该问题；已有参考时将问题改为是否搜索补充参考，只围绕关键缺口搜索。
- 轻量 Research 正常路径保持 5–6 张方向候选并写入画布，由用户自由选择 1 张或多张，不限定固定张数。用户明确授权代选时可直接选择最匹配的一张或多张。
- 品类、目标时长和画幅足以搜索时，不再单独追问风格、成片形态、旁白或 CTA；这些内容由已选参考辅助收敛或并入生成前确认。
- Research 完成后必须形成唯一的 `Brand Direction Lock`：可回溯品牌/产品事实的品牌性格、一句视觉母题、全部已选方向参考及各自贡献、6–8 个可观察风格词、光色/材质/空间规则、运镜语法、节奏曲线、转场机制和禁止迁移内容。
- 脚本与分镜必须消费该锁：用“品牌事实/个性 → 可见的主体反应 → 匹配的镜头运动 → 品牌收束”构建节拍。每个镜头写明起点、路径、终点和叙事目的；禁止把所有品牌都编成“慢推产品 → 两个特写 → Logo 定格”。
- 有参考图时，风格词不能取代真实媒体输入。先把旧 旧 H3 意图改写成连续自然语言，再通过审批链调用 Seedance 2.5 前核对全部已选方向图的真实 path，放入 `reference_image_paths`，使用 `mode=multimodal`，并在 Prompt 中逐张声明贡献与禁区。未选候选图不得进入视频调用。Research 分析后不新增结果审核，直接并入原有生成前确认。

## 5. 产品主角短广告路线

- 仅承接单条轻量、不超过 15 秒、具体产品或系列为唯一或绝对主角的商业广告；只有“产品视频/产品宣传片”等弱信号且缺少时长或交付目标时，补问后再选路线。
- 选中后先读取 [product-motion.md](references/product-motion.md)。需要设计视觉锚点或关键帧时再读 [product-visual-techniques.md](references/product-visual-techniques.md)；准备生成视频时再读 [product-h3-compile.md](references/product-h3-compile.md)。
- 不把 references 全部预读。简单单条广告可在产品身份、时长、画幅、卖点和视觉方向明确后直接生成；只有存在身份、审美或多镜头依赖时才增加锚点与故事板。

## 6. 品牌视觉过程路线

- 默认 12 秒、9:16、无字幕；收集品牌名、品类关键词、资产、slogan、平台、时长和画幅。
- 视觉基线：暖乳白纸底、暖墨黑字标、姜黄/低饱和黄主色，纸纤维、印刷网点、接触阴影和实体卡片厚度；默认不使用暗黑赛博风。
- 画布先建立草稿字标帧、成品主视觉帧、6–12 个拼贴碎片、最终定格与时间线：0–1.2 秒草稿；1.2–5 秒错峰翻页；5–7 秒主色扩张；7–10.5 秒成品完成；10.5–12 秒定格。
- 先整理静态关键帧，再生成纸张、卡片、拼贴碎片的连续运动。明确 Y 轴翻页、错峰波浪、物理厚度、当前起止状态和同步纸张声；不要求视频模型承担精确品牌文字或网格计数。
- 使用 Hub 原生后期叠加已授权 Logo/字标、slogan 和最终静帧。生成前把关键帧、资产来源、概念/授权边界和声音策略落到画布，并用 `question` 请求确认。

## 7. 产品材质诗意路线

- 默认建议 15 秒，画幅由投放场景决定；为每项素材标明 `identity`、`product`、`texture`、`ingredient`、`process`、`archive`、`typography`、`transition` 或 `outro` 角色。
- 核心视觉是正俯视发光白色亚克力灯箱档案陈列：真实产品/包装与原料、标签纸、书页、包装展开图、描图纸和抽象材料共同构图。
- 时间按视觉呼吸分配：完整陈列 2.5–4 秒，材质微距 0.5–1.2 秒，工艺动作 1.5–2.8 秒；至少包含材质微距、可见工艺动作和发光留白收束，不均分整数秒。
- 切点由摆放、翻页、遮挡、材质变化、明暗或形状匹配驱动。默认避免普通 Hero、生活方式广告、酒吧/派对/霓虹、科技 HUD、随机图表和过度 glossy。
- 生成前把品牌事实/来源、资产角色、视觉方向、非均匀时间码分镜、声音策略和授权说明落到画布并请求确认；环境声、动作声和已确认旁白均由 旧 MiniMax H3 随视频原生生成，旁白不另建独立 TTS；独立 BGM 只在确认后制作。

## 8. 轻量品牌展示路线

- 仅在官网首屏、产品页、App、店铺或轻量发布载体明确时使用；未说明载体不选此路线。未指定时建议 15 秒，按平台选择 16:9 或 9:16。
- 先收集 Logo/字体/色彩规范、产品图/包装/UI 截图/官网资料、产品功能与已核验主张、CTA、受众、平台、语言、字幕和旁白需求。
- 在画布建立品牌事实表和来源清单；每个身份资产记录稳定 ID、角色、路径/节点、来源、核验目标、真实性状态和发布说明。
- 按品类选择故事脊柱：AI/SaaS“意图 → 能力 → 执行 → 可见结果 → 证明 → 品牌收束”；实体产品“英雄展示 → 交互 → 功能特写 → 使用场景 → 结果 → 品牌收束”；服务/公司“问题 → 过程 → 证据 → 成果 → 承诺”。
- 生成前完成逐节拍分镜：15 秒 5–8 个主要节拍，每节拍写起止时间、视觉主体/资产 ID、主动作、产品证明、文案停留、转场与运动承接；每节拍只有一个主动作。
- 先用真实静帧、产品主视觉、UI 底板或运动首帧，再按确认节拍生成视频。每个 Prompt 必须自包含当前动作、真实参考用途、音频策略和不可改变的品牌约束；已确认旁白需把精确文案、语言、声线、语气和时间点写入 旧 MiniMax H3 Prompt，由视频原生音频承接，不为同一内容重复叠加独立声轨。

## 9. 未来系统蒙太奇路线

- 只在单一品牌锚点贯穿、且重点是高速系统视觉而非剧情广告时使用。锚点可为已授权的 Logo、产品、App、品牌人物或材料；没有可用锚点时索要一张参考图，不凭文字虚构现有品牌标识。
- 先完成本 Skill 的品牌事实、来源和 Logo 真实性核验，再读取 [future-system-montage.md](references/future-system-montage.md)，按其中的输入锁定、时间轴、Prompt 与声音规则制作。
- UI 密度、节奏和视觉模式只用于编写 Prompt，不是 `drama_request_paid_batch → 用户批准 → drama_resume_paid_batch（Seedance 2.5）` 的 `vendor_params`；全片不得引入第二主体、伪造第二个 Logo 或让系统图形遮挡主体。

## 10. 统一生成前确认与交付检查

生成任何媒体前，必须把品牌事实表、来源摘要、路线、`Brand Direction Lock`、时间码分镜、屏幕文案/CTA/旁白、声音策略和授权边界落到画布，并通过 `question` 请求确认；用户明确继续后才生产。执行过 Research 时，在这同一次确认中展示全部已选方向图及各自贡献，并确认 旧 H3 调用预览的 `reference_image_paths` 含其真实 path；不新增 Research 结果审核。

视频生成完成并已落到画布后、最终合成与交付前，必须调用一次 `question` 询问：“视频已生成，是否需要为成片生成一条独立 BGM？生成音乐会增加音乐生成与合成时间；不生成则保留当前 旧 H3 原生旁白、环境声和动作声。”提供“生成 BGM”和“不生成，保留原生声音”两个选项。若用户此前已明确选择需要或不需要独立 BGM，遵循已有选择，不重复询问。

用户选择生成 BGM 后，直接派发 `vendor=official`、`model_id=music-3.0`、`mode=instrumental`，不再询问音乐模型，也不传固定或近似时长参数。生成后只把音乐裁切到目标成片时长并为尾部制作自然渐出，再与 旧 H3 视频原声混合合成；不循环、变速或改编音乐，不重新剪辑或改动视频画面，也不替换原生旁白、环境声和动作声。视频 Prompt 必须排除 BGM，避免重复配乐。只有用户明确指定其它音乐模型，或能力查询确认 `music-3.0` 当前不可用时才调整模型，并向用户说明，不得静默切换。

交付前确认身份资产可追溯、事实未扩写、Logo 未拉伸/重绘、产品与 UI 清晰、节奏和转场符合所选路线、文字可读、声音不重复叠加、最终视频与资产已落到画布。回复成片路径/画布产物、时长画幅、路线摘要、素材来源和必要权利提示。
