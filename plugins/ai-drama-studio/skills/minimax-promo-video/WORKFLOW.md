> 来源：MiniMax Design 本机 Skill。以下内容已迁移到 OpenDramaFlow 语义。若原工作流与本页顶部的运行时合同冲突，以运行时合同为准。

## 运行时合同

- 项目事实来自 `drama_get_state`，正式剧本/角色/镜头写入使用 `drama_update_plan`。
- 图片由 Codex Image Gen 任务闭环生成；视频由 Seedance 2.5 付费审批链生成；确定性媒体处理使用本地 FFmpeg。
- MiniMax H3 相关模型描述只作为旧提示词迁移背景，不能作为当前供应商参数或能力声明。
- 未接入的供应商、画布节点 API、音色克隆、TTS、音乐生成、3D 编辑器或剪辑工程写入必须显式停止，不得用占位结果冒充成功。

# 宣传视频

根据产品或品牌信息制作可发布的宣传片，并保持宣传主张、产品身份、节奏和发布渠道要求一致。

## 制作模式

- **快速初版**：使用合理创作默认值，减少中间确认；高成本媒体生产前仍须确认简报和完整前期方案。
- **导演模式**：在简报、创意方向、脚本、分镜、主视觉和粗剪后分别停下确认。

用户要求自动继续时，可以采用推荐创作默认值，但不能据此虚构产品主张或跳过生成前确认。

## 输入

接受以下任意组合：

- 产品或品牌描述；
- 产品官网或其他已授权来源链接；
- 演示文档、PDF、规格说明或推广简报；
- 产品图、界面截图、包装或渲染图；
- 已有视频、参考广告或视觉参考；
- 必须保留的宣传主张、活动信息、行动号召、渠道、受众和语言。

区分已核实的产品事实与拟议广告文案。来源互相冲突时，先让用户确认哪份资料为准，再写宣传主张。

## 阶段 1：确认产品简报

提取并确认：

- 产品名称和品类；
- 一句话定位及解决的用户问题；
- 目标受众和推广目标；
- 不超过三个优先卖点；
- 事实主张的证据或来源；
- 推广语气和期望观众反应；
- 行动号召；
- 最终交付语言、时长、画幅和发布渠道；
- 已有身份资产及其使用注意事项。

把以上内容整理成简洁产品简报。必要素材缺失、主张无法核实或交付要求互相冲突时，先停止并补齐信息。

## 阶段 2：选择创意方向

用户没有给出方向时，提供两到三个产品专属方案并推荐一个。常用结构包括：

- **品牌认知**：情绪钩子 → 品牌价值 → 记忆点 → 品牌收束；
- **产品发布**：制造好奇 → 产品亮相 → 优先功能 → 证据 → 行动号召；
- **功能演示**：痛点 → 产品交互 → 可见结果 → 用户收益 → 行动号召；
- **转化推广**：问题 → 方案 → 证据 → 价值或紧迫感 → 行动号召。

避免泛化视觉奇观。每个主要节拍都应展示产品事实、收益、交互、场景或情绪回报。

## 阶段 3：撰写脚本和节拍方案

围绕已确认时长建立简洁的 hook-body-CTA 结构：

1. **Hook**：建立可识别的痛点、欲望、反差或产品亮相；
2. **Body**：展示产品机制、核心收益和支持证据；
3. **CTA**：留下一个明确动作和稳定收尾画面。

每个节拍记录：

- 时间范围和作用；
- 需要时写旁白或对白；
- 画面文案及可读停留；
- 视觉主体、动作、构图和镜头意图；
- 展示的产品事实或收益；
- 前后转场；
- 声音意图：原生声音、音效、音乐、语音或静音。

文案应适合口播，不要把所有卖点塞进一条短片。分镜必须覆盖完整时长，不能留下无法解释的空段。

## 阶段 4：建立视觉系统

生产素材前先定义可复用视觉语言：

- 产品身份和参考素材优先级；
- 构图与留白规则；
- 色板和布光逻辑；
- 字体行为和安全区域；
- 镜头节奏和转场语言；
- 人物、界面、标识、包装和可读文字规则。

只有在能明显提升一致性时才生成主视觉或分镜关键帧。拼贴图或接触表只用于帮助用户检查序列，不应成为固定模型输入，也不能把宫格版式带入最终视频。

导演模式下，生产前确认脚本、节拍方案和视觉系统。快速初版模式下，集中展示一份简版前期方案，并在用户明确确认后继续。

## 阶段 5：生产音画素材

按稳定顺序制作已确认素材：

1. 准备或生成主视觉，并保持产品身份；
2. 按节拍方案生成视频片段或连续序列；
3. 只有脚本需要时才制作语音；
4. 已确认采用原生音频时，明确要求生成有声视频，并写入已确认的配乐和音效方向，不依赖平台隐式默认值；否则制作独立配乐或音效层；
5. 使用最新批准的画面和声音素材完成最终合成。

避免重复音轨。视频片段已有已确认的语音或音乐时，不要再次生成同一层。更换模型或制作路线会明显改变结果时，说明差异并让用户决定。

## 阶段 6：验收和交付

交付前检查：

- 产品身份、界面、包装和标识忠于已批准来源；
- 主张与价格符合确认的证据，或已明确标记为概念文案；
- Hook、Body 和 CTA 均存在且容易理解；
- 时长、画幅、语言和渠道符合简报；
- 文字可读且不过度拥挤；
- 各镜头视觉风格和产品外观一致；
- 声音同步、平衡，没有重复旁白或音乐；
- 结尾停留足够长，便于识别产品和行动号召。

交付最终视频、简短创意摘要、已确认文案、关键来源说明和剩余注意事项。用户需要中间素材时，清楚分组整理。

## 失败恢复

- 来源无法访问：请用户提供导出文件、截图或简洁产品说明；
- 产品主张不确定：删除，或在核实前标记为拟议文案；
- 参考身份漂移：回到最可靠的已确认来源重新生成；
- 主视觉或片段失败：简化节拍、减少同时动作，或拆成更短镜头；
- 画面文字不稳定：减少可见文案，并在用户接受后改为后期文字方案；
- 声音冲突：明确语音和音乐各自唯一来源，再重建混音；
- 所选模型无法满足硬性要求：说明能力差异并让用户选择兼容路线。

## 边界

本 Skill 用于制作短宣传视频，不适用于长篇剧情片、未经证实的产品主张、未授权品牌仿制、普通视频剪辑，或用户期待成片时仅交付脚本。
