# 未来系统蒙太奇

仅在 `brand-ad` 已选择“未来系统蒙太奇”路线后读取。保留本 Skill 的品牌事实、授权、Logo 和文案真实性规则；本卡只补充系统视觉的执行规则。

## 输入与主体锁定

1. 用 `本地媒体核验（view_image、ffprobe 或 FFmpeg）` 提取唯一品牌锚点的真实轮廓、关键几何、内部识别点、构图和不可改变的身份特征。锚点只可为已授权的 Logo、产品、App、品牌人物或材料。
2. 默认建议 15 秒、16:9、中等 UI 密度、极密节奏、结尾 Hero 定版和原生声音；用户指定时长、画幅、主体和视觉模式优先。可选模式为符号系统、仿生产品、机能人像、应用身份。
3. HUD、坐标、细线、不可读参数和代码感图形只能作为边缘系统层，不能遮挡主体、伪造第二个 Logo 或生成大段可读文字。

## 视觉与声音

- 使用无边界黑/白/灰空间、高反差明暗脉冲、强侧光与逆光轮廓光。
- 每 0.25–0.45 秒发生一个明确视觉事件，但主体身份、轮廓和关键几何始终可辨。
- 将 HUD 线框、扫描线、tracking 点、glitch 闪断、粒子重建、玻璃/芯片、金属压印、岩石刻痕、技术织物、App 容器和黑白反相作为同一主体的材质证据，不做无关炫技。
- 默认按总控冻结请求并执行 Seedance 2.5 原生声音：低频启动与脉冲、电子 click、玻璃嗡鸣、扫描 whoosh、金属/石材摩擦和 glitch 断点，均与图层弹出和快切卡点同步。
- 默认禁用 ASCII 幽灵、低保真旧照片、CRT 档案、字符遮罩和暖模拟纪录片节奏；仅在用户明确要求时将其作为附加层，不取代主体锚点。

## 结构化成片

先在画布写入主体事实、模式、时长画幅、视觉/声音策略和以下时间轴，再用 `question` 请求确认。其它时长等比压缩或扩展，但保留事件顺序：

1. **启动与锁定**（0–2 秒）：黑场中核心几何点亮，主体从暗场或画面边缘出现；准星、轮廓光和扫描完成身份锁定。
2. **系统拆解**（2–5 秒）：推入关键结构，在线稿、粒子、网格和反相剪影间转换；拆出外轮廓、核心识别点和边缘结构，再快速合拢。
3. **材质证明**（5–10 秒）：同一主体依次在玻璃/芯片、金属压印、岩石刻痕、凝胶或技术织物中显现；每次转换均保留可辨识几何，不加入新主体。
4. **系统身份回收**（10–13 秒）：主体进入极简 App 容器或系统空间，短促 recap 前述材质，黑场停顿后由粒子/扫描重新聚合为完整主体。
5. **Hero 定版**（13–15 秒）：无边界灰色 Hero 空间中完整主体悬浮或定格，极细定位线收拢并淡出；精确品牌 Logo/字标仅用已授权资产经 本地 FFmpeg 确定性合成叠加。

## 生成与交付

1. 先整理锚图和必要材质关键帧。每条视频 Prompt 必须写明不可改变的主体结构、当前材质事件、起止状态、轻量 HUD 边界和同步声音。
2. 所有片段使用同一主体锚图作为 reference；不得在跨片段时更换主体或核心几何，也不得用文字描述替代主体。
3. 确认后生成并按时间轴剪辑，保留原生声音。仅在用户明确要求时添加字幕、精确文字或额外音乐。
